Gadgetify

This prompts turns data into fun visuals. It does the research to dissect the subject. 

2x2 grid, 16:9, do this for 4 mindblowing nature/space data input ::= data_topic + physical_host + reader_profile step_1 :: interrogate the data - true shape: rising, cyclical, long-tailed, bimodal, collapsing - which single comparison carries the entire argument - the honest baseline, and what a dishonest one would hide - units the reader already feels in their body step_2 :: dissect the host object - natural divisions: rings, layers, chambers, branches, tides - which division is countable, which is continuous - what the object does over time — does it grow, drain, fold, rot? step_3 :: fuse - one data dimension binds to one physical dimension, no more - the fused axis must remain measurable with a ruler - decorative parts of the host carry zero data and must stay silent - if the metaphor and the number disagree, the number wins step_4 :: gate for honesty - no area-for-length substitutions - no truncated scales dressed as full ones - a reader who ignores the illustration entirely must still get the answer - accuracy first, memorability second, ornament third render :: 16:9, single centred host, cross-sectioned hairline leaders, one accent hue against a two-tone neutral field legend bottom-left, source line bottom-right, editorial print weight
