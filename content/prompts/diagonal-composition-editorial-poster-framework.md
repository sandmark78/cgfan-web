## Prompt

【主题】：____
【主体类型】：群像 / 空间 / Typography / 单体对象
【主体内容】：____
【中文标题】：____
【英文标题】：____
【对角方式】：群像运动 / 空间透视 / 字体推进 / 对象倾斜
【主轴方向】：左下→右上 / 右下→左上
【配色】：____
【日期 / 机构】：____
【比例】：9:16

生成一张具有强设计感的对角构图海报。

先建立一条清晰的斜向视觉主轴，再围绕这条主轴组织主体、Typography 和留白，而不是先堆装饰元素。

让主体本身形成对角势能：
群像型用人物动作、大小和排列形成连续斜向运动；
空间型用建筑切面、透视和光影形成斜向收束；
Typography 型用大号文字沿斜轴推进、放大、裁切和叠压；
单体对象型用物体自身轮廓、重心和倾斜姿态自然形成斜势。

整张图只保留一个主要视觉方向，其他元素只负责跟随或平衡，不制造新的视觉竞争。

主体承担主要视觉重量，保留 25%–40% 留白。中文标题承担视觉重心，小型英文和日期信息集中在 1–2 个信息区。色彩控制在 2–4 种，通过尺度、裁切、叠压和非对称排版增强张力。

重点不是“画一条斜线”，而是让主体、文字和留白共同形成对角阅读路径。

Editorial Graphic Design，成熟、克制、清楚、有张力，像真实文化展览海报。
