## Prompt

生成一张【画幅比例】极简黑白灰“构图参考图”，主题为【构图主题】，英文副标题为【英文标题】。整体气质像设计师的版式研究卡、构图草稿、视觉参考图，白底黑字浅灰图形，克制、轻盈、留白充足。

这不是说明书，不要大段解释，不要步骤讲解，不要 how to use，不要信息过多。只保留少量文字：中文标题、英文副标题、1句短辅助文案、少量小字、日期【日期】、细线、小圆点、极简符号。

标题位置必须根据【构图主题】变化，不要固定左上角。标题、图形、小字要共同参与构图。灰色块面要作为构图骨架，直接表达【构图逻辑关键词】。整体更像“构图案例示例”，而不是“设计原则讲解页”。

风格倾向：【极简 / 瑞士平面 / 构成主义 / 设计草图】
灰色图形类型：【圆形 / 椭圆 / 弧线 / 斜切块 / 分区块面 / 环绕路径】
辅助短句：【辅助短句】

避免：说明书感、教程感、信息过多、标题全堆左上、模板感过强、彩色、复杂装饰、AI乱码。
