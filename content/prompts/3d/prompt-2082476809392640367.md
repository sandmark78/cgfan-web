以【物品】为核心，创作一组精致、轻盈、清新治愈的渐变彩色竹编艺术品。整体严格参考图片中的细竹篾手工编织风格，准确还原纤细竹条、疏朗镂空、柔和渐变、天然竹色、细密收边与温暖光影，呈现真实、高级、耐看的手工作品质感。 

主体准确提炼【主体形状】最优美、最具辨识度的正面轮廓。整体扁平轻薄，带有极轻微的自然拱度，外形完整饱满，比例协调，曲线柔和流畅，视觉重心稳定。造型简洁但不空洞，一眼能够识别主体，同时保留自然、安静、精巧的设计感，不笨重、不僵硬、不夸张、不变形。

内部统一使用纤细、扁平、柔韧且表面光滑的天然细竹篾。单根竹篾宽度约为主体最大宽度的1/25—1/30，所有竹篾宽度和厚度基本一致，边缘平整圆润，保留浅米色天然竹纤维、细微竹节与轻微手工痕迹。竹篾必须连续完整、弯曲顺滑、张力均匀，不出现断裂、毛刺、开叉、起皮、分层、碎裂或粗糙崩坏。

外轮廓使用比内部竹篾宽约1.4—1.6倍的天然原竹色竹条弯曲定型。外框沿主体轮廓连续闭合，粗细均匀，弧线自然，转折柔和，不出现生硬折角、鼓包、断口或歪斜。边缘使用极细竹丝进行细密、均匀、规整的缠绕收边，接头隐藏自然，结构牢固干净。

主体内部采用【编织结构：横纵方格疏编 / 斜向菱格疏编 / 自然交错疏编】。相邻竹篾之间的净间距约为竹篾宽度的2.5—3.5倍，镂空面积约占内部面积的60%—68%。每个方向约排列7—10根主要竹篾，具体数量根据【主体形状】自然调整。孔格大小相对统一，中心区域略规整，靠近边缘处随轮廓自然弯曲、收束与缩小。

所有竹篾采用清晰、连续、正确的“一上一下”穿插关系，交叉节点自然压合，层次分明，贴合平整，不悬浮、不穿模、不粘连、不重复、不突然中断。整体编织疏朗通透、舒展有序、疏密均衡，保留轻微真实手工变化，但不能机械僵硬、松散凌乱或密不透光。

色彩采用【渐变色1】—【渐变色2】—【渐变色3】的柔和渐变，并按照【渐变方向：左至右 】自然过渡。约30%—40%的竹篾保留天然浅米色，使原竹色与彩色区域相互穿插、自然融合。 

彩色部分呈轻薄透明的植物染色质感，色彩渗入竹纤维内部，仍能清晰看到天然竹纹。不同颜色之间通过细腻中间色缓慢过渡，相邻竹篾颜色连续，单根竹篾也可沿长度产生轻微渐变。整体色调清透、柔和、低饱和、明亮而不刺眼，不出现生硬分区、明显色带、厚重油漆、塑料涂层或荧光色。

根据【主体形状】加入少量【辅助结构：叶片 / 果梗 / 花萼 / 枝条 / 羽片 / 尾部】。辅助结构同样使用纤细竹篾制作，尺寸小巧，比例准确，造型简洁，与主体连接自然牢固。叶片可使用浅橄榄绿、鼠尾草绿或原竹色，枝梗可保留天然浅棕色与细微竹节。辅助结构只用于增强辨识度，不宜过大、过密或抢夺主体视觉中心。

画面展示【作品数量】件同系列竹编作品，保持相同的主体轮廓、竹篾宽度、编织密度与制作工艺，仅在渐变深浅、编织角度或摆放方向上产生轻微变化。作品自然平放在打开的米白色艺术书页、浅色手工纸或温润亚麻桌面上，呈纵向或斜向错落排列，彼此保持舒适间距，画面留白充足。

温暖柔和的午后自然光从【光线方向】斜射，在纸面上形成清晰但边缘柔和的竹编网格投影。阴影与真实镂空结构准确对应，突出竹篾的薄度、弧度、交叉层次和轻微立体感。背景以奶油白、浅米色、暖灰色和浅原木色为主，构图简洁安静，不出现复杂环境或多余装饰。
