## Prompt


输入 A 是 一种 机械 设备 或 小工具（例如：复古相机、机械手表、V8 发动机、游戏机）。
将 该 对象 分解 成 3 个 功能 层  :
机架（外壳）：识别 主 机身 框架 或 外壳。
引擎（内部）：识别 主要 的 内部 机制。
（例如：相机 -> 快门 与 反光镜。手表 -> 发条 与 擒纵机构。发动机 -> 活塞）。
界面（控制）：识别 按钮、旋钮，或 镜头 元件。
2.  容器
目标：“爆炸式构造” 台面 摄影。
表面：干净、浅纹理 的 木工 工作台 或 切割 垫。
布局：爆炸视图（Knolling）。机器 被 拆解 成 各个 组件，并 以 空间 方式 排列 以 展示 它们 如何 配合 组装。
3.  构造
悬挂：主要 部件（机架）由 微型 脚手架 提升 支撑 或 被 微型 黄色 起重机 悬挂。
叙事：一支 1:87 比例 的 建筑 工人 队伍（安全帽、反光背心）正在 积极 组装 机器。
动作：他们 在 焊接 齿轮、起吊 镜头，或 在 桌上 研究 蓝图。
车辆：微小 叉车 或 平板 卡车 正 在 运送 螺丝 和 弹簧。
4.  视觉
指引 线：细长、发光 的 蓝色 激光 线 或 全息 线 将 分离 的 零件 连接，描绘 从 桌面 到 悬挂 部件 的 装配 路径。
五金：微小 的 螺丝、垫圈 与 弹簧 以 整齐 行列 排列（Knolling 风格）在 桌面，等待 安装。
5. 灯光 与 氛围:
灯光：明亮 的 工作室 灯光。均匀、无阴影 的 照明（高调 High Key），以 确保 每一 处 机械 细节 可见。
质感：机器 零件 的 哑光 灰/黑 与 建筑 设备 的 鲜艳 黄色 之间 的 对比。
输出：一幅 图像，1:1 纵横比，微距 摄影，“迷你世界” 美学，技术 精准。
