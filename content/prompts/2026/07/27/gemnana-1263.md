## Prompt

[BRAND NAME]。以创意总监与时尚摄影师的身份，创作一张带有 UI 叠加层的高端编辑风格样册图像。
1. 主体（前卫街头服饰与自然姿态）：
一位时装模特居中站立于干净的摄影棚内。
时装风格：造型为醒目、概念性的“现代前卫街头服饰”，诠释 [BRAND NAME] 的美学与配色。融合高端时尚与街头文化：实验性廓形、解构式叠搭、夸张的比例、独特材质组合与大胆细节。应当创新且具编辑感，但仍立足于街头服饰，避免基础休闲服的感觉。
姿态：模特呈现自然、放松、不费力的编辑风姿（例如双手随意插在口袋、微微倚靠、目光离开镜头或温和地看向镜头）。绝对不要机器人般、僵硬或“T 字站姿”。
2. UI 覆盖层（磨砂玻璃矩形）：
在模特躯干正前方叠加一枚大型竖向悬浮 UI 元素。
形状与轮廓：简洁的竖直矩形，圆角，边框为干净的 2px 纯白实线描边。
材质（玻璃拟态）：矩形内部为“磨砂玻璃”。被这片玻璃遮挡的服装部分必须进行强烈模糊（高强度高斯模糊），形成半透明的纵深效果，而模特其余部分保持极其清晰锐利。
3. UI 内容（极简且小巧）：
在磨砂玻璃面板内，放置两个纯白单色元素：
居中：官方 [BRAND NAME] 标志，精确居中。
标志下方：在明显高于底边的位置，放置两个非常小、极简的白色导航箭头（一个指向左“”）。它们应低调，尺寸约为标准 UI 图标的 50%。
4. 摄影风格与构图（严格取景）：
风格：高端编辑类时尚摄影。具有真实胶片颗粒，考究的柔和棚拍光线，强调面料质感。必须呈现真实摄影效果，而非 CGI 渲染。
背景：无限延展的纯白摄影棚曲面背景。
取景（严格约束）：画面为广幅全身照片。模特全身（从头顶到脚底）以及整个 UI 覆盖层必须完全包含在画面边界之内。主体和 UI 绝对不能有任何裁切。主体四周须留出非常宽裕的大量留白（“空气”）。
