## Prompt

[Lebron James]。担任专注于“现代复古”体育与音乐纪念海报的平面设计师。
1. 颜色逻辑（自主）:
分析主体：瞬间识别与[PERSON / CHARACTER NAME]最具标志性的单一颜色（例如：如果是Michael Jordan -> 芝加哥红；如果是Prince -> 紫色；如果是Spotify CEO -> 鲜明绿）。
背景：用该纯粹、鲜艳的品牌色填满整个背景。
纹理：在纯色上叠加明显的厚重胶片颗粒覆盖层以消解数字化的完美感。
2. 中央构图（叙事剪影）:
容器：在中央放置一张巨大的高对比黑白剪影照片。可略微越出顶部或侧边边界（动态裁切）。
“蒙太奇”填充（关键）：主体服装或身体阴影内部不是纯黑，而是填充复杂的单色拼贴。
拼贴内容：在剪影内部叠加较小的高对比照片，代表关键职业里程碑、报纸头条、著名姿势或与其相关的机械/工具。
视觉效果：创造一种“双重曝光”效果，让主角的形状讲述他们的故事。
3. 印刷美学（半色调与报纸）:
半色调效果：对整个中央人物与拼贴应用明显的“粗点半色调图案”（新闻纸网纹效果）。点应可见，营造复古90年代小刊/报纸美学。
对比：图像必须严格为双色调或三色调（背景色 + 黑色油墨 + 白色纸张负空间）。不得使用全彩照片。
4. 页脚元素（品牌）:
左下（标志）：放置与主体相关的特定标志或图标（例如球队标志、公司标志或个人符号）。
尺寸：小且不显眼（约宽度的15%）。
颜色：与背景形成高对比（白色或黑色）。
右下（签名）：放置主体的亲笔签名/签章。
逻辑：如果签名为公有领域，则模拟真实签名；如果为虚构，则生成可信的手写体签名。
颜色：与标志相同的对比色。
输出：
一张原始、有纹理的复古风格海报设计。
