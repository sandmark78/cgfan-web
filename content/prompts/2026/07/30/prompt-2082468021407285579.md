## Prompt

```
《品牌LOGO提案》完整提示词：

你是一名资深品牌设计师、Logo设计师、视觉艺术指导与Editorial版式设计师。

请根据我填写的品牌信息，为同一个品牌直接设计并生成一套【四图品牌视觉识别提案】。不要先输出图片提示词，也不要只给方案或页面大纲，直接生成4张独立图片。

【品牌信息】

中文品牌名：【填写】
英文品牌名：【填写】
品牌行业：【填写】
主要产品或服务：【填写】
品牌定位与目标人群：【填写】
品牌核心理念：【填写】
品牌性格关键词：【填写3—5个】
品牌标语：【填写，或根据理念重新提炼】

Logo灵感来源：【填写】
Logo类型：【抽象符号 / 汉字融合 / 字母图形 / 几何符号 / 徽章等】
希望Logo表达的含义：【填写】
不希望出现的元素：【填写】

整体视觉风格：【填写】
主色调：【填写】
辅助色与点缀色：【填写】
主要材质：【填写3—5种】
摄影或空间氛围：【填写】
主要产品、包装与应用场景：【填写】

画面比例：【默认4:5竖版】
文字语言：【中文为主 / 英文为主 / 中英结合】
补充要求：【填写】

如果部分信息没有填写，请结合品牌行业、定位和理念自动补充合理方案，不要因为非关键字段为空而停止。

━━━━━━━━━━━━━━━━━━
【设计任务】
━━━━━━━━━━━━━━━━━━

先统一设计并锁定品牌系统，包括：

- 一个原创、清晰、可独立使用的Logo图案
- 中文与英文品牌字标
- 主色、辅助色与点缀色
- 字体、材质和摄影语言
- 从Logo中延展出的辅助图形与纹样
- 产品、包装、物料和空间应用方式

Logo不能只有纯文字。必须包含一个具有设计感的独立Symbol，与品牌理念相关，具备清晰轮廓、负空间或几何结构，缩小后仍可识别，并适合压印、烫金、刺绣、雕刻和空间标识。

避免直接使用普通行业图标，例如香炉、茶叶、女性侧脸、房屋、普通树叶、莲花、祥云、太极或传统印章。需要经过抽象、简化和重新构成，形成原创品牌符号。

Logo一旦确定，四张图中的核心轮廓、内部结构、字标和组合方式必须保持一致，不能每张图重新设计。

━━━━━━━━━━━━━━━━━━
【四张图片内容】
━━━━━━━━━━━━━━━━━━

图1｜品牌世界观与概念封面

用一张大型品牌主视觉建立品牌情绪和世界观，同时清晰展示完整Logo、中文名、英文名、概念主标题、品牌宣言、3—5张情绪或材质图片，以及少量手写概念注释。

采用“大标题＋大型主视觉＋完整Logo＋非规则情绪拼贴”的结构。Logo必须明显可见，但不能压过主标题和品牌氛围。

图2｜Logo概念与符号生成逻辑

以超大的Logo Symbol作为视觉中心，展示完整Logo、中英文字标、横版与竖版组合、简化版本、概念来源草图、负空间与结构关系。

加入少量手绘轮廓、箭头、圈选和设计师手写注释，让观众理解Logo为什么这样设计。页面要有研究感，但不能做成复杂工程图或传统VI表格。

图3｜品牌视觉语言与设计系统

展示品牌主色、辅助色、字体、材质、摄影语言、Logo局部裁切和辅助纹样。

颜色需要与真实材质建立联系，例如石材、纸张、金属、玻璃、植物或织物。辅助图形必须从Logo轮廓、内部曲线、负空间或笔画中提取，不能添加无关装饰。

版式采用规整网格与自由拼贴结合，加入大型字体、纵向文字、细线和少量手写标记。

图4｜品牌应用与体验场景

展示品牌如何进入真实产品、包装、纸品、织物和空间。根据行业选择5—7个合理触点，例如主产品、礼盒、手提袋、卡片、标签、制服、毛巾、金属标牌、门头、前台或空间导视。

采用“一张大型产品或空间主视觉＋4—6张应用细节”的结构。完整Logo、独立Symbol和辅助纹样需要分层使用，不要让每件产品都重复印完整品牌名称。

━━━━━━━━━━━━━━━━━━
【整套视觉要求】
━━━━━━━━━━━━━━━━━━

整套图片采用高级品牌提案、Editorial杂志设计、艺术指导板与现代视觉识别案例相结合的设计语言。

每张图都必须有：

- 一个醒目的大型主标题
- 一个简短副标题
- 一句核心说明
- 2—4个关键词或信息标签
- 2—4处有意义的手写注释
- 一个明确的视觉中心
- 约25%—35%的留白

主标题要参与构图，可以放大、裁切、错位、纵向排列，或与图片、Logo互相穿插，不能只是普通页眉。

手写标记可以使用短句、箭头、圈选、下划线或简单草图，用于解释Logo、字体、颜色、材质和工艺。手写内容必须简短、清晰、有意义，避免无意义乱码和满屏涂鸦。

四张图使用统一的品牌名、Logo、字体、配色、材质、摄影氛围、边距和辅助线，但版式不能完全相同：

- 图1：大主视觉与情绪拼贴
- 图2：超大Logo与结构研究
- 图3：色彩字体与材质系统
- 图4：产品空间与应用落地

避免普通PPT、简单Moodboard、传统VI表格、素材网站Mockup合集、整齐重复的宫格、大段正文、信息拥挤、低质量3D材质、廉价金色、颜色漂移和Logo结构变化。

━━━━━━━━━━━━━━━━━━
【输出要求】
━━━━━━━━━━━━━━━━━━

请直接生成4张独立的4:5竖版图片，不要把四张内容合并成一张拼图，也不要先输出生图提示词。

按照以下顺序生成：

1. 品牌世界观与概念封面
2. Logo概念与符号生成逻辑
3. 品牌视觉语言与设计系统
4. 品牌应用与体验场景

如果当前一次只能生成一张图片，请直接从图1开始，并按照同一套已锁定的Logo和视觉系统继续生成图2、图3和图4，不需要重新规划或更换设计方向。
```
