# 李煜词意留白海报

## Prompt

```
Larus Canus
Aug 23
提示词：
【诗词原句】：填写一句带有明显情绪和画面感的古诗词
【两字主题】：从诗句中提炼 2 个核心字
【核心情绪】：流不尽 / 理不清 / 忘不掉 / 留不住 / 等待 / 思念等
【情绪动作】：流走 / 缠绕 / 残留 / 消失 / 褪色 / 漂离等
【小主体】：水迹 / 丝线 / 旧窗 / 花瓣 / 灯 / 舟 / 信笺等
【主色】：填写 1–3 种主要颜色
【浅压纹】：旧河道 / 线痕 / 人影 / 花影 / 水纹 / 月晕等
【地点与日期】：填写
生成一张 9:16 竖版东方诗意留白艺术海报，将【诗词原句】里的【核心情绪】转化为一种可见的【情绪动作】。
使用纯白或轻微冷调的高级手工艺术纸作为背景，保留真实纸纤维、纸浆颗粒和自然压痕。画面保持约 65%–70% 的有效留白，不使用巨大主体压满画面。
只放置一个占画面约 15%–25% 的【小主体】，再加入极小人物或极少量叙事元素。重点不是直接解释诗句，而是通过【情绪动作】让情绪发生在空间里。
背景加入与主题有关的低对比浅浮雕【浅压纹】，压纹必须有含义，例如曾经流过的路径、已经消失的人影、被拉直又缠绕的线痕、褪色花影或旧物留下的位置。远看保持干净，近看才发现这些“残留”。
颜色使用【主色】，可以漂亮、清透、有情绪，但不要为了悲伤全部做成黑白灰。让颜色随着距离和时间逐渐变淡、褪去或进入纸面。
线条、水边、花落轨迹等必须连续、柔和、自然，避免大量断点、碎线和凌乱的 AI 纹理。
中文主标题使用【两字主题】，采用现代宋体或明朝体，可通过字距、轻微错位、细线或局部延伸增加设计感，但必须保证汉字完整、准确、清晰。
同时加入小字号原诗句、地点、日期和简短英文标题。整体效果像古诗情绪、材料实验、纸张压纹与高级编辑海报的结合。
避免：普通古风插画、传统山水画、旅游海报、巨大主体、人物哭泣、乌云暴雨、情绪表达过度直白、背景米黄发旧、线条断裂、压纹没有含义、颜色灰闷、密集文字和廉价 3D。
```
