## 简介

古风人物朝代策展海报框架 — 将不同朝代人物与现代编辑设计融合的策展式海报模板。核心亮点：真实人物摄影 + Typography + 手绘线条的三层叠加设计，器物参与构图，线条从人物轮廓自然延伸至留白。

## Prompt

生成一张 9:16 高级古风人物 Editorial Poster。

【朝代】：[汉 / 唐 / 宋 / 明 / 其他]
【人物气质】：[庄静 / 明艳 / 清雅 / 端雅 / 其他]
【服饰】：[填写]
【代表器物】：[2–3 个]
【中文主标题】：[填写]
【英文标签】：[Dynasty / 其他]
【短文案】：[填写]
【主色调】：[填写]

以一位真实、优雅、美丽的年轻东亚人物作为画面主体，保留真实皮肤纹理、自然五官和干净肤色，人物姿态、发型、服饰和神态符合对应朝代气质，不要做成普通古装剧照或汉服写真。

加入 2–3 个具有朝代辨识度的代表器物，让器物同时参与构图，例如玉璧、漆器、博山炉、团扇、琵琶、茶盏、汝窑瓷器、手卷、折扇、窗棂等。

版式采用「真实人物摄影 + Typography + 手绘线条」的现代策展式人物海报设计。

使用一个醒目的中文主标题，搭配少量英文 Dynasty 标签、1 句短文案和极简器物关键词。文字需要与人物姿态、器物和留白发生关系，而不是简单放在画面角落。不要日期、编号、时间和页码。

人物局部手绘轮廓线必须清晰可见，这是整个系列的核心视觉元素。

在人物发髻、肩膀、手臂、衣袖、裙摆等位置加入约 2–4 段纤细手绘线：贴合人物轮廓一小段 → 中断 → 脱离人物 → 延伸进入留白。不要完整描边人物，也不要让线条包围全身。

同时让手绘线条从朝代器物本身自然生长，例如：
唐：团扇圆弧、飘带、乐舞轨迹
宋：茶烟、卷轴、山水线
汉：玉璧圆弧、博山炉烟线
明：折扇扇骨、窗棂几何线
线条数量适中，既要明显具有设计感，又要保留足够呼吸空间。

整体呈现高级独立杂志、东方文化策展、古风人物 Editorial Poster 的视觉质感，让不同朝代拥有不同的人物人格、配色、器物和线条语言，同时保持统一的系列设计系统。
