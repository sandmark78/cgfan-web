## Prompt

16:9 横向电影画幅，东方神界超尺度皇家建筑摄影，1980s Hong Kong fantasy wuxia cinematic language + modern photorealistic cinematic VFX。摄影机站在高空神宫巨殿与镜面水台交界处，人眼高度约 1.4 米，35mm 镜头，平视略仰，不航拍。

近景左侧与顶部压入异常巨大的白玉殿墙、通天雕花玉柱、厚重重檐、斗拱与梁架，建筑只能看到局部，柱顶和檐口被画面裁切，体现超尺度巨构。材质极精工华贵：温润高抛光象牙白神玉、墨青黛青琉璃重檐、深朱宫廷漆柱、油润深木、少量鎏金与精密龙纹祥云浮雕。

中景是一片极宽阔的高空镜面水台，水面清澈平静，倒映天空、宫殿与人物。2 位成年东方女仙身穿淡青与杏粉长裙，坐在水台尽头，仅作尺度参照。

镜池之外是浩瀚洁白云海，近景空气极其清澈，远处有少量巨大立体积云。极远处第一主宰是一座山脉级主神宫，距离数公里却依然异常巨大、横向极宽、台基厚重，采用中深青灰宫体、黛青重檐、暗朱柱列、深木梁架和暖白玉基座；远景受空气透视后略淡、略偏青灰，但必须保持中深色质量，明显深于云海，不得白化。

主神宫之后再出现尺度更高一级的超巨大远古神壁 / 天界圣壁，珍珠灰白与淡青灰神玉材质，直入高空，体量远超前方主宫，形成“主宫已经如山，神壁却更加巨大”的三级尺度递进。

整体构图：近景巨殿局部 → 镜面水台 → 极小人物 → 云海负空间 → 深色主神宫 → 超级神壁 → 蓝天。

光线为晴朗高空强方向日光 + 清澈冷蓝天空补光，整体高调、明亮、清透，高光不过曝，阴影不死黑。色彩舒爽有对比：天空蓝 + 象牙玉白 + 黛青墨青 + 深朱红 + 少量暖金 + 淡青杏粉人物色，禁止全白、全金、统一蓝色偏色、灰雾、远景缩小、远景白化、人物过大、塑料材质、游戏概念图感。
