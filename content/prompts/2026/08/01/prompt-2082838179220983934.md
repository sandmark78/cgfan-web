纯二次元人物立体纸雕通用提示词

以【人物角色】为核心，创作一幅精致华丽、轻盈梦幻、层次丰富的纯二次元人物立体纸雕艺术作品。

整体融合高质量日系二次元角色设计、多层叠纸、精细镂空、浅浮雕纸艺与幻想装饰插画。人物必须呈现纯粹鲜明的动漫风格，画面材质则明确表现为真实纸张制作的立体纸雕作品，兼具唯美动漫角色的感染力与精细手工纸艺的收藏级质感。

采用9:16竖版全身构图，【人物角色】位于视觉中心，占画面约60%—70%。人物身形修长协调，姿态轻盈自然，可表现为【回眸凝望 / 缓步前行 / 漂浮空中 / 执物而立 / 迎风旋身 / 准备战斗】。身体、长发、衣袖、裙摆、披风与飘带形成流畅优美的S形动态曲线，轮廓完整清晰，避免僵硬呆板。

人物面部必须是高质量纯二次元美型设计：精致柔和的动漫脸型，清澈灵动的大眼睛，细密睫毛，小巧鼻唇，细腻自然的神态与清透肤色。眼神富有情绪和故事感，不偏真人写实，不做低幼Q版。人物脸部保持完整平滑，纸雕感主要体现在头发、服装、配饰与场景结构中。

服装根据【角色设定】进行原创设计，可为【魔法少女礼服 / 幻想长裙 / 偶像舞台服 / 校园制服 / 哥特洋装 / 精灵服饰 / 战斗制服 / 轻科幻服装】。服装轮廓华丽优美，裙摆、袖口、披风与蝴蝶结层层展开，边缘融入精致的【花瓣纹 / 星月纹 / 羽毛纹 / 蝴蝶纹 / 蕾丝纹 / 魔法纹】纸艺装饰。纹样细腻但不过度镂空，保留完整纸面与清晰色块，避免破碎杂乱。

头发柔顺飘逸、层次分明，具有清晰动漫发束与柔和渐变高光。发尾、飘带与披风可轻微卷曲、翻折或悬浮，呈现真实纸张弧度和立体厚度。

人物可手持【魔法杖 / 花束 / 长剑 / 雨伞 / 提灯 / 水晶球 / 书本 / 权杖 / 乐器】，道具与动作、视线及故事主题自然互动。

背景围绕【故事主题】构建梦幻多层纸雕场景，可加入【月夜花园 / 星空神殿 / 樱花街道 / 幻想森林 / 魔法图书馆 / 天空之城 / 海边车站 / 偶像舞台 / 哥特城堡 / 未来都市】。

前景设置花卉、枝叶、蝴蝶、羽毛、星屑、光粒与装饰纸框；中景突出人物；远景呈现建筑、天空、月亮、云层、树林或城市轮廓。不同纸层之间保持清晰距离、遮挡关系与自然投影，形成舞台式、橱窗式的立体纵深空间。

装饰元素选择【樱花 / 玫瑰 / 百合 / 蝴蝶 / 星星 / 月亮 / 羽毛 / 水晶 / 雪花 / 光环】，沿人物发丝、衣袖、裙摆与飘带自然延伸，形成优美视觉引导线。装饰丰富但疏密有序，不遮挡人物面部与主体轮廓。

整体以【主色调】为核心，可选择【粉白与浅金 / 蓝白与银色 / 紫粉与香槟金 / 红黑与暗金 / 薄荷绿与奶油白 / 黑紫与玫瑰红 / 天蓝与樱花粉】。色彩清透梦幻、鲜明协调，背景适度降低饱和度，突出人物主体。局部加入珠光纸面、渐变纸层、描金、烫银、细闪与半透明纸张，增强精致感和视觉冲击力。

使用柔和主光、环境微光与轮廓光，让光线从镂空缝隙和纸层之间轻柔透出，形成自然阴影、朦胧光晕与清晰浮雕厚度。突出纸张纤维、裁切边缘、折叠弧度、卷曲结构和层叠空间，避免塑料模型感与厚重纸板感。

整体构图华丽饱满但不拥挤，人物始终是绝对视觉中心。画面细节丰富却秩序清晰，动态流畅，色彩统一，最终呈现唯美、梦幻、精致、灵动的纯二次元立体纸雕艺术效果，具有高端动漫海报与收藏级纸艺装置质感。
