# 东方暗黑档案实验博物馆海报

**作者**: Larus Canus  
**日期**: 2026-08-13  
**评分**: 68/80 (9+8+7+9+9+8+9+9=68)

## Prompt

```
【主题】：填写展览主题
【中文主标题】：填写 2–6 个汉字
【英文标题】：填写英文标题
【副标题】：填写展览说明
【核心图像】：异兽 / 傩面 / 甲胄 / 星图 / 其他古代图像
【黑色构图】：斜切 / 圆弧 / 纵向断层 / 夜幕负空间 / 其他
【主题短句】：填写一句简短文案
【时间地点】：填写展览信息
【画面比例】：9:16

设计一张「东方暗黑档案」实验博物馆海报。

使用泛黄旧纸、宣纸纤维、扫描颗粒、墨迹渗透和自然印刷磨损作为背景质感，以大面积墨黑平面结构制造强烈正负形关系。黑色必须参与构图，可使用斜切、巨大圆弧、纵向断层、夜幕负空间等形式，每个主题使用不同结构，避免简单套版。

核心图像采用古代文物或神话元素（异兽、傩面、甲胄、星图等），以拓片、线描、工笔或金箔质感呈现，与墨黑平面形成强烈对比。文字排版采用传统书法与现代无衬线体混排，主标题可使用篆书、楷书或实验性字体设计。

整体风格：东方暗黑美学、实验博物馆、档案感、正负形构图、传统与现代碰撞。
```
