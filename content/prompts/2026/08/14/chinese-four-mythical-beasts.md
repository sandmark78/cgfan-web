# 中式四大神兽：火麒麟雷麟烛龙玄龟

**作者**: 古一  
**日期**: 2026-08-13  
**评分**: 72/80 (9+9+9+9+9+9+9+9=72)

## Prompt

```
1.火麒麟
中式神话异兽美学，古老、神圣、威严、炽烈、祥瑞又危险，火麒麟全身像，体态雄健修长，鹿角般分叉长角高高向后生长，龙首与麒麟面结合，鼻梁高挺，口吻威严，双目像熔金般灼亮，鬃毛浓密蓬松，像燃烧的赤金火焰从头颈一路延伸到脊背与尾端，身体覆盖细密坚硬的暗红与赤金鳞甲，胸腹与四肢保留部分兽类肌肉感与厚实毛发，四蹄像被火焰包裹的黑金玉石，踏地时迸出微弱火星与热雾，长尾如燃烧的丝绸般飘动，站在昏暗山岩或神殿台阶上，背景有淡淡烟尘、热浪与火光，画面干净，主体强烈，中式祥瑞神兽的史诗感

2.雷麟
中式雷系神兽美学，凌厉、神圣、迅捷、威严、耀眼、带天罚感，雷麟全身像，整体体态比火麒麟更轻捷，像鹿、龙、豹的结合，身形修长流畅，四肢爆发力强，头部高昂，分叉长角带冷银与电光质感，双目散发明亮蓝白雷光，鬃毛向后炸开，像被雷电激起的银白火焰，身体覆盖深蓝、冷黑与银灰色鳞甲，鳞片边缘有极细电弧闪动，四蹄踏地时有碎裂电光与浮尘，尾巴细长有力，末端像一道发亮的雷鞭，背景可以是高崖、暴风云层或神殿屋脊，画面干净，主体极强，具有中式天罚神兽气质

3.九幽烛龙
中式上古异兽美学，幽暗、远古、神秘、禁忌、压迫、超现实，九幽烛龙盘踞于黑暗洞窟或冥河崖壁，巨大的龙躯修长而厚重，鳞片呈暗黑、铁灰与深红交错的金属质感，龙首古老狰狞，长须低垂，额骨隆起，双角像烧焦的古木或黑曜石，眼睛如两点幽红烛火，在黑暗中稳定燃烧，口鼻间吐出淡淡白雾与赤色火星，脊背有一排缓慢发光的骨刺与火纹，腹部鳞片较浅，带冷白灰色，身体边缘被昏暗火光勾勒，周围缭绕浓雾、灰烬、暗火与幽深阴影，画面干净，轮廓主导，具有冥界古龙的压迫感

4.青冥玄龟
中式神话巨龟美学，厚重、古老、沉稳、神秘、静默、带宇宙感，青冥玄龟全身像或半身中景，龟壳巨大圆拱，壳面布满古老裂纹、星宿纹理与山岳般起伏的纹路，颜色为深青、黑灰与冷青铜色，边缘带岁月磨损感，头部像龙龟结合体，嘴喙厚重，眼神古老安静，带超越时间的气质，颈部粗壮而有层层甲片，四肢像石柱般稳固，爪尖厚重，壳边与背脊缭绕少量灵雾，背上可以有极少量微小植被、古碑或积尘，站在海雾、冥河浅滩或古老祭台上，画面干净，具有中式洪荒神兽的沉稳崇高感
```
