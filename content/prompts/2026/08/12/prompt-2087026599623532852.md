# AI口红推荐报告：自拍生成专属色号信息图

**作者**: Derek Wen｜德里克文  
**日期**: 2026-08-10  
**评分**: 60/80

## Prompt

```
上传一张自拍，让 AI 直接生成你的专属口红推荐报告,让 AI 帮你做个人形象的分析建议！
今天这期想拆的，就是一个非常有实用价值的玩法：口红推荐系统。

上传一张自拍，再指定一个口红品牌，
GPT-Image-2 就可以基于你的整体气质、肤色倾向、唇部状态和品牌风格，生成一张完整的：“口红推荐报告信息图”

里面可以直接包含：


你可以把它理解成一句话：
不是让 AI 帮你“试个色”，而是让它帮你做一轮“可视化决策”。

🎯 核心提示词：

你是一名专业美妆顾问、形象分析师与信息图设计师。

请基于用户上传的自拍，以及指定的口红品牌，生成一张“口红推荐报告信息图”。

目标：
根据人物的整体气质、肤色倾向、妆容适配度与唇部特征，推荐3—5个适合的口红色号，并以清晰、专业、具有品牌调性的方式呈现。

品牌：
【填写品牌名称，例如：Dior / YSL / Armani / Chanel / Tom Ford】

画面内容包含以下结构：

1. 左上区域：用户自拍与基础分析
- 展示用户自拍头像
- 提炼肤色倾向、整体气质、适合的色彩方向
- 用简短中文标签概括，例如：冷调感、柔和感、通勤感、气场感等

2. 中部主体区域：口红推荐矩阵
- 推荐3—5个适合的口红色号
- 每个色号展示上唇试色效果
- 保持同一人物、同一角度、同一光线，只变化唇色
- 每个色号配中文名称或编号
- 标注色彩印象，例如：温柔豆沙、通勤裸红、气质玫瑰、显白红棕、约会浆果等

3. 右侧或下方区域：使用场景建议
- 为每个推荐色号匹配适用场景
- 例如：通勤、约会、逛街、宴会、拍照、日常素颜

4. 底部总结区域：结论建议
- 给出“最推荐色”“最百搭色”“最显气色色”等总结
- 用简洁中文写出一句购买建议或选择建议

品牌视觉风格请自动匹配：
- Dior：优雅法式灰白 + 银色点缀
- YSL：黑金高对比，性感强烈
- Armani：低饱和灰调，高级克制
- Chanel：极简黑白，理性时髦
- Tom Ford：深色奢华，电影感
- 可根据品牌自动延展相应视觉语言

画面要求：
- 整体像高端美妆顾问报告或品牌试色分析图
- 中文清晰准确
- 布局整洁，信息完整，适合社交媒体分享
- 保持同一人物身份一致，只比较唇色差异
- 风格高级，不要像普通电商截图

注意：
这是基于图像与气质的视觉推荐，不要做医学判断或绝对结论。

这类提示词的核心公式是：
自拍输入 + 品牌限定 + 试色矩阵 + 场景建议 + 信息图呈现。
```
