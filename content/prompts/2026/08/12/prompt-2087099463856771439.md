# 古松神域：矩形框构图的东方仙侠悬空长廊

**作者**: Soran  
**日期**: 2026-08-11  
**评分**: 71/80

## Prompt

```
这组最妙的地方，是它把一棵松，从风景里的树，直接抬成了整个世界的中轴。

• 真正控制画面的先不是宫殿，也不是云海，是那个巨大的矩形框。长廊、桥面、远景和人物全都在往它收，所以你看的不是一棵树，是一座被精确陈列出来的神域。
• 树的位置也很狠。它没有老老实实站在中心点上，树干偏、树冠横伸、重心侧压，刚好把过于工整的轴线打松一点，画面就有了“秩序里长出生命”的劲。
• 两侧长廊特别关键。重复柱列把视线一格一格往里送，下面整片云海又把地面直接抹掉，所以这组会有一种很强的悬空感，像人在廊中走，眼睛已经先被送进另一个世界。
• 人物一直被压得很小，只在桥上、廊边、框前轻轻出现。这种处理很聪明，既把尺度立住了，也让整个空间多了一点仪式感，像所有人走到这里，都会自然慢下来。
• 最值得抄的是它的观看方式。前景建筑没有抢着讲自己多复杂，反而主动退成边框、通道、引线，把全部注意力让给框中的那棵树。世界观一下就干净了，也更高级。
所以这组最打人的点，不是“云上海景”那种常规奇观，而是它把“看见”这件事本身设计出来了。你不是在看风景，你是在被允许看见一棵被供起来的树。
同一条提示词我放评论区，感兴趣可以直接拿去跑自己的模型。
欢迎返图 ⤵️
这组图真的很适合拿来做“误入天宫”的氛围感模板，月亮、云海、巨构建筑和极小人物一叠，随手一发就很有神性。

• [圆形月门 + 云海宫阙 + 极小白衣人物] → 先用“框中框”把视线锁死，人物越小，天宫越显得不可抵达，画面一上来就有那种被神域吞没的震撼感。
• [悬崖长廊 + 白衣背影 + 斜线透视] → 把人放进漫长的路径里，情绪会从“看风景”变成“去赴一场很远的约”，这种构图天然会让人脑补故事。
• [巨型宫墙 + 松树探出 + 云海压满画面] → 建筑做绝对主角，人物只负责标尺，尺度反差一出来，普通仙侠感就会直接升级成史诗感。
• [冷白月光 + 清晨侧逆光 + 云层高反差雾化] → 光线不能太暖，偏冷的银蓝调会把“人间”抽掉，只留下清、空、静，正适合这种带点神性的东方幻想场景。
• [石材雕刻肌理 + 薄雾层次 + 轻胶片颗粒感] → 质感越克制越高级，不能做成纯 CG 的硬亮假面，保留一点真实空气和颗粒，画面才会像“真的有人拍到过仙境”。
```
