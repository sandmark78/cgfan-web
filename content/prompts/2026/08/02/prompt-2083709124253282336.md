# 油纸伞上坐姿：古风轻悬浮写真

**作者**: VoxCat  
**日期**: 2026-08-02  
**评分**: 70/80

## Prompt

```
人物坐在一把竖立放置的油纸伞上，一条腿自然弯曲抬起，从伞面上方轻轻翘过雨伞边缘，小腿顺着伞的弧度自然下垂，脚尖微微绷直，作为画面中唯一清晰可见的一条腿。另一条腿收在伞的另一侧，被伞面大部分遮挡，仅通过膝部轮廓、衣摆变化或身体重心暗示受力关系，不完整露出脚部。上半身微微后仰或侧转，腰部放松，肩颈舒展，一只手向外伸展保持平衡，另一只手自然垂落或轻搭在腿侧，整体呈现轻盈、优雅又带一点悬浮感的伞上坐姿。适合真人COS、古风写真、东方幻想人像，也可以搭配低机位、侧面视角或轻微广角透视自由变化。
```
