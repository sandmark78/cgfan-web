# 东方留白修养箴言海报

**作者**: Larus Canus  
**日期**: 2026-08-03  
**评分**: 68/80 (9+8+8+8+9+8+9+9=68)

## Prompt

```
【修养箴言】：【填写经典短句】
【两字主题】：【从短句中提炼】
【核心含义】：【等待 / 自省 / 守真 / 归本等】
【主体材料】：【黑金属 / 朱漆镜 / 青花瓷 / 原木 / 琉璃等】
【主色体系】：【填写 2—4 种明确颜色】
【视觉隐喻】：【开启 / 对照 / 保留 / 剥离 / 回归等】
【背景压纹】：【内部结构 / 倒影轮廓 / 器形线 / 年轮等】
【地点与日期】：【填写】

生成一张 9:16 竖版东方留白艺术海报，将【修养箴言】转化为具有当代装置感的视觉隐喻。

使用带有真实纤维、压痕和纸浆颗粒的高级手工艺术纸作为背景，保留大面积留白，并加入与主题有关的低对比浅浮雕【背景压纹】。压纹必须参与表达含义，远看克制，近看才发现细节。

画面设置一个轮廓清晰、具有真实体积和材质触感的【主体材料】，通过【视觉隐喻】表现【核心含义】。加入一个占画面约 1%—2% 的极小人物，建立巨物与人的尺度关系。

色彩使用【主色体系】，可以大胆、鲜明，但保持明确主次。让颜色通过釉光、裂隙、倒影、流光、漆面或材料内部进入空间，不要始终局限于黑白灰，也不要使用廉价霓虹特效。

中文主标题使用【两字主题】，采用现代宋体、明朝体或雕刻感衬线字体。可以通过字距、错位、弧线或短线增加设计感，但必须保证汉字完整、准确、清晰。

同时加入小字号的【修养箴言】、地点、日期和简短英文标题。整体呈现东方修养、材料艺术、当代装置与高级编辑海报的结合。
```
