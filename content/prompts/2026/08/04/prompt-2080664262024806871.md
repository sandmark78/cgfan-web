# 东方留白诗意艺术海报

**作者**: Larus Canus  
**日期**: 2026-07-24  
**评分**: 68/80 (9+8+8+8+9+8+9+9=68)

## Prompt

```
【原诗句】：【填写】
【两字标题】：【从原句中摘出】
【剩余短句】：【填写】
【核心重物件】：【填写】
【浅压纹】：【填写】
【极小叙事元素】：【填写】
【主色光】：【填写】
【英文标题】：【填写】
【日期】：

生成一张 9:16 竖版东方留白艺术海报，把【原诗句】的意境重新转化为画面。

使用温润象牙白手工艺术纸背景，保留纸纤维、纸浆颗粒和高级印刷质感。在大面积留白中加入与主题相关的【浅压纹】，采用低对比浅浮雕形式，远看克制，近看有层次。

画面设置一个轮廓清晰、材质厚重的【核心重物件】，搭配极小的【极小叙事元素】，形成巨大尺度与微小人物之间的反差。使用【主色光】通过裂隙、雾气、倒影或光路进入周围空间，成为唯一明确的颜色焦点。

构图避免普通居中展示，让深色实体、浅色压纹、小人物和大面积留白形成清晰的空间关系。整体要有厚重感、轻盈感、尺度感和诗意。

文字只保留：
【两字标题】
【剩余短句】
【英文标题】
【日期】

使用现代宋体或明朝体，排版克制清晰。整体像东方诗意与当代装置艺术结合的高级展览海报。

避免传统古风插画、旅游山水、背景纯空白、主体过淡、多人、过多颜色、密集文字、廉价 3D 和夸张特效。
```
