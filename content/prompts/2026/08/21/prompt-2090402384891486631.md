# 博物馆图录风：文化知识可视化

**作者**: Derek Wen｜德里克文  
**日期**: 2026-08-20  
**评分**: 62/80

## Prompt

```
很多人用 AI 生图，最常见的问题是好看，但没信息量。精致，但讲不清楚。
像海报，却不像真正能拿来做文化科普的内容。
大多数人还在让 AI 画一张图，而不是 做一张有知识结构的信息图。

今天要拆的这个方向，我觉得非常值得关注：博物馆图录风。

🎯 核心提示词：

请基于【主题】自动生成一张“博物馆图录风格的中文拆解信息图”。

整张图要求结合真实主视觉、结构拆解、中文标注、材质说明、纹样含义、色彩含义和核心特征总结。

你需要根据【主题】自动判断最合适的：
主对象、服饰体系、器物结构、时代风格、关键部件、材料工艺、色彩方案和版面结构，用户不需要再提供其他信息。

整体风格应为：
国家博物馆展板、历史服饰图录、文化 / 博物馆主题信息图。

背景使用：
米白、绢白、浅茶色等纸张肌理。

版式固定为：
顶部主标题 + 副标题 + 简介；
左侧结构拆解区（中文引线标注关键部件 + 局部细节放大）；
右上材质 / 工艺 / 纹理区；
右中纹样 / 色彩 / 含义区；
底部穿戴顺序 / 构成流程图 + 核心特征总结。

所有文字必须为简体中文，清晰、工整、可读，不得出现乱码、错字、英文或拼音。

这类提示词的核心公式是：

博物馆主视觉 + 结构拆解 + 材质工艺 + 纹样色彩 + 中文标注 + 总结归纳。

💡 核心逻辑

博物馆图录风真正厉害的地方，不是“看起来高级”。
而是它把 AI 生图从“视觉装饰”，推到了“知识表达”。

一句话理解：

让读者不仅看过，还能带走一个清晰结论。
📌 一句话总结

博物馆图录风真正厉害的地方，不是把文化内容做得更“好看”，而是把原本分散、抽象、难讲清的知识，整理成一张既能看、又能学、还能收藏的视觉图录。
```
