# 粗颗粒旅行印记：照片转版画

**作者**: 蛋黄堡  
**日期**: 2026-08-20  
**评分**: 62/80

## Prompt

```
把旅行照片变成【粗颗粒旅行印记】

转绘提示词：

请以当前上传的一张照片为唯一参考，在一次图像编辑生成中，将其制作成一张完整、独立的高级旅行设计海报。

不要添加其他参考照片，不要多图拼接、九宫格或生成海报展示样机。只输出海报正面本身。

一、整体版式

采用精确3:4竖版构图。

画面上下分成两个高度接近1:1的水平区域，各占整体约50%。分界清晰、水平、克制，不要让上下内容相互侵占。

上半部分为高保真真实摄影区。

下半部分为同一照片的“TRAVEL RELIEF PRINT”限色旅行浮雕版画区。

上下必须表现同一个地点、同一主体和同一段旅行记忆。

二、上半部分：高保真保留原照片

上半部分必须忠实保留当前上传的原始照片。

准确保持：

- 主体身份和数量
- 人物或动物的姿态、动作与方向
- 建筑结构、地形和街道方向
- 交通工具及核心物体
- 原始观察角度和空间透视
- 重要物体的相对位置
- 真实材质
- 自然光影
- 原有色彩氛围

上半必须明确看起来仍是一张真实摄影作品，不能变成版画、插画、绘画或AI重建照片。

只允许进行非常轻微、克制的高级摄影调色、动态范围整理和极薄胶片颗粒，使照片具有独立旅行杂志、建筑摄影、艺术出版物和摄影展览的质感。

为适配上半区域，可以自然延展天空、地面或周边环境，但延展内容必须符合原照片的透视、纹理、光线和空间方向。

不得拉伸、挤压、扭曲、镜像、复制主体、改变人物、移动物体、重塑建筑、替换天空或使用模糊照片副本填充边缘。

如果自然延展不合理，宁可使用与整张海报一致的干净象牙色纸张边距，也不要破坏原照片。

三、下半部分：TRAVEL RELIEF PRINT

下半部分使用温暖的奶油色或象牙色天然版画纸背景。

纸张应具有：

visible paper grain,
subtle paper fibers,
slightly rough matte surface,
warm archival paper,
natural pigment absorption.

从上半照片中选择一个最具识别度的主体，或者一个能够代表照片含义的场景整体，将其重新制作成一枚独立悬浮在纸面上的“旅行版画印记”。

保留决定原照片识别度的：

- 主体外轮廓
- 姿态或行进方向
- 主要明暗分区
- 透视方向
- 关键结构
- 材质纹理节奏
- 标志性色彩
- 最重要的空间关系

主动删除：

- 复杂背景
- 重复建筑结构
- 大量窗户
- 密集人群
- 无关车辆
- 微小招牌
- 杂物
- 细碎纹理
- 次要物体
- 无法准确生成的文字

下半不是将整张照片降低饱和度、增加颗粒或套用版画滤镜。

必须先理解照片中最重要的视觉信息，再将其重新制版、压缩、套色和印刷。

四、版画媒介与质感

使用以下混合版画语言：

travel relief print,
limited-palette screen print,
rough lithograph,
woodcut texture,
linocut texture,
stencil print,
photographic texture reduction,
handmade printmaking,
distressed pigment,
broken halftones,
irregular ink coverage,
rough dry-brush edges,
paper showing through,
slight color misregistration,
granular shadows,
hand-masked boundaries,
naturally missing ink.

版画应具有粗颗粒、手工套印和旧旅行印刷品的质感。

颜料为不透明、哑光的印刷油墨，不是透明水彩。

允许出现：

- 油墨覆盖不均
- 局部缺墨
- 断裂网点
- 粗糙干刷边缘
- 纸张透底
- 轻微套色偏移
- 颗粒化阴影
- 手工遮罩的不规则边界
- 局部磨损
- 少量原照片纹理被压缩后的印刷痕迹

不同色层应像分别套印在纸张上，而不是通过数字渐变平滑融合。

不要使用精确矢量描边。

不要让主体变成企业Logo、干净图标或普通扁平插画。

五、下半构图

版画主体放置于下半区域中央或略微偏上。

主体占下半高度约38%–52%，根据照片内容自然调整。

版画主体不能铺满整个下半区域，周围必须保留大量温暖象牙色纸张留白。

主体边缘不能形成完整的矩形照片框。

使用以下方式让边缘自然消失：

- 不规则刷印
- 撕裂般的油墨边缘
- 断裂网点
- 缺墨区域
- 颗粒逐渐减少
- 纸张自然透出
- 局部结构突然中断

整体具有“一枚旅行记忆被压印在纸张上”的感觉。

风景照片可以保留少量地形、天际线、水面或建筑节奏，但不能完整重建所有背景。

人物或交通工具照片应优先突出主体轮廓、姿态和运动方向。

建筑照片应保留最有识别度的体块、屋顶、窗洞比例或结构节奏。

六、限色色盘

从上半原照片中提取3–5种主要颜色，压缩成高对比、哑光的有限油墨色盘。

通常包括：

- 一种最深的轮廓墨色
- 一种温暖纸张底色
- 一至两种主体颜色
- 一个小面积高光色或标志性色

暖色照片可以使用：

赭橙、砖红、焦黄、橄榄绿、炭灰、暖米色。

冷色照片可以使用：

灰蓝、海水蓝绿、墨绿、石墨灰、雾灰和暖象牙色。

夜景可以使用：

深墨绿、炭黑、褪色蓝、暗红和少量暖黄色灯光。

保留原照片中最具有识别度的一处亮色作为视觉记忆点，但不要同时使用大量鲜艳颜色。

所有颜色必须像层层套印的实体油墨。

禁止平滑数字渐变、霓虹发光、高饱和商业配色和透明水彩晕染。

七、文字系统

在版画主体下方放置极少量文字。

主标题使用以下准确文字：

“[英文主标题]”

主标题控制在1–3个英文单词，使用克制的打字机体、等宽衬线体或旧档案字体，水平居中。

主标题下方放置以下准确旅行关键词：

“[关键词1 / 关键词2 / 关键词3]”

关键词使用3–5个简短英文单词，以斜杠分隔，小于主标题，字距自然，像旧旅行照片背面的打字说明。

所有文字必须逐字准确，不得修改、增删、拼错或生成额外字符。

除以上两行外，不要添加编号、年份、品牌、Logo、二维码、网址、宣传语、长段落或无意义文字。

如果没有提供文字，则保持无文字设计，不得自行编造标题。

八、整体气质

整体应像一张由旅行摄影制作而成的小型限量版画：

直接、朴素、怀旧、温暖、安静、粗粝、略带探险感与私人旅行记忆。

高级感来自：

- 准确的限色色盘
- 主体信息压缩
- 粗颗粒印刷纹理
- 不完整的版画边缘
- 纸张留白
- 克制的文字
- 上下照片与版画之间的视觉呼应

它不是传统写实绘画，也不是普通照片滤镜。

它是一枚由原照片重新制版而成的旅行记忆印记。

九、强制避免

Avoid:

multiple-photo collage,
grid layout,
poster mockup,
frame,
wall scene,
hand holding poster,
upper-half illustration,
redrawn photograph,
changed identity,
changed face,
changed pose,
altered architecture,
duplicated objects,
mirrored extension,
stretched photograph,
blurred-photo side fill,
full-poster printmaking filter,
clean vector tracing,
smooth digital gradients,
polished flat illustration,
generic logo silhouette,
full rectangular photo crop in the lower panel,
detailed background reconstruction,
watercolor wash,
transparent watercolor,
sticker collage,
travel icons,
airplane icon,
passport graphics,
map pins,
architectural blueprint lines,
random circles,
decorative grids,
glossy 3D,
anime,
cartoon,
neon colors,
full lower-panel coverage,
hard rectangular frame,
excessive typography,
fake brands,
gibberish text,
watermark,
cheap souvenir template.

最重要的规则：

上半部分必须是对当前原照片的高保真摄影保留。

下半部分必须将原照片中最重要的主体或场景，重新制成一枚限色、粗颗粒、边缘不完整、悬浮在大面积象牙纸留白中的旅行版画印记。

整张海报必须在一次生成中完成，不要分别生成素材，不要使用代码拼接，不要输出多张图片。
```
