## Prompt

8h
Prompt:
【主题】：____
【核心器物】：____
【主标题】：____
【副标题】：____
【主色】：____
【贯穿线性元素】：枝条 / 水纹 / 斜线 / 自由曲线 / ____
【小面积点缀色】：____
设计一张 2:3 竖版东方器物 Editorial 海报。以暖象牙白纸本、轻微纤维与印刷颗粒为底，结合真实器物摄影、中文字体、英文小字、线稿与少量东方图形。
画面保持中高信息密度，但避免堆砌。用 2–3 个主要视觉团块组织版面，并设计一条贯穿画面的“视觉脉络”，连接标题、器物和辅助图形，让元素彼此穿插：文字可被器物局部遮挡，线条绕过主体，纹样可从器物延伸到版面，浅色大字藏在背景中。
Typography 建立明显的四级尺度：巨型视觉字 / 中型中文标题 / 小型英文 / 极小信息文字，横排、竖排和错位组合，局部越界但整体受隐形网格控制，形成“乱中有序”的编辑感。
器物避免简单居中陈列，可使用完整主体 + 局部裁切 + 淡线稿等多层呈现。背景留白区域也加入低对比度的大字、植物线描、器物轮廓或纹理，让留白有内容但不喧宾夺主。
整体采用低饱和主色，只加入一次小面积高识别度点缀色，用于标签、细线或局部图形。画面要优雅、克制、有现代东方文化设计感。
避免：PPT 式分区、元素各自散开、大面积无内容空白、单纯“器物 + 标题”摆放、模板感 Logo、编号、四角星芒、过度国潮装饰。
