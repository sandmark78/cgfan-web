# 宠物品牌生成器

**作者**: 橘子多  
**日期**: 2026-08-26  
**评分**: 57/80

## Prompt

```
橘子多
把宠物做成完整生活方式品牌｜万能提示词👇
请根据我上传的【宠物照片】，把这只宠物打造成为一个完整、真实、高级的原创生活方式品牌
一、保留宠物辨识度
准确保留宠物真实特征：
品种
毛色与花纹
脸型
耳朵形状
眼睛
鼻子
毛发纹理
标志性表情
独特身体特征
不要把它变成普通、通用的卡通猫狗。
可以将宠物形象转化为：
真实肖像、手绘线稿、极简插画、局部轮廓、剪影或品牌图形，
但始终保持原宠物高度辨识度
二、自动创建品牌
根据宠物的外貌、性格与整体气质，自动设计：
简洁高级的英文品牌名
原创 LOGO
宠物专属图形符号
品牌字体
2–4种品牌主色
一句简短自然的英文 Slogan
包装设计语言
统一视觉识别系统
品牌不要做成普通宠物店风格
更像：
独立设计师品牌
生活方式品牌
文创品牌
高级宠物品牌
编辑设计品牌
整体具有真实商业价值
三、自动延伸品牌产品
将同一套品牌视觉应用于丰富的真实生活物件
可以自动从以下产品中选择，也可以根据品牌气质继续创造更多产品：
日常生活
陶瓷马克杯
咖啡杯
保温杯
水杯
玻璃杯
餐盘
宠物碗
托盘
杯垫
文具
记事本
手账
笔记本
日历
明信片
贺卡
文件夹
标签
贴纸
随身物品
钥匙链
手机壳
卡套
钱包
徽章
挂件
行李牌
家居
抱枕
毛毯
地毯
香薰蜡烛
收纳盒
桌面摆件
装饰画
海报
穿戴
T恤
卫衣
帆布袋
围裙
棒球帽
袜子
宠物围巾
品牌延伸
产品包装盒
礼盒
纸袋
吊牌
品牌卡片
快递包装
品牌贴纸
限量收藏包装
四、设计原则
不要只是把宠物照片机械地印到每一个产品上。
每种产品都根据材质和用途重新设计。
例如：
有些使用宠物头像，
有些只使用线稿，
有些使用品牌 Logo，
有些只使用局部耳朵、鼻子、尾巴、爪印等视觉元素，
有些可以完全不出现宠物，只保留品牌符号。
让整套产品看起来真正经过专业品牌设计
五、视觉风格
现代生活方式品牌
高级商业摄影
极简编辑设计
独立设计师品牌
高级产品 Mockup
使用：
自然低饱和配色
柔和高级棚拍光线
真实陶瓷、棉布、纸张、金属、织物等材质
细腻阴影
大量留白
克制排版
真实产品比例
避免：
廉价淘宝风
儿童卡通感
元素堆砌
过度鲜艳
把同一张宠物照片重复贴满所有商品
六、输出方式
生成一张高级品牌产品视觉展示板。
采用整齐的：
6宫格 / 8宫格 / 9宫格
展示不同品牌产品
每一个格子只展示一种产品
所有产品保持：
相同品牌名
相同 Logo
相同字体系统
相同色彩系统
相同视觉语言
但每件产品的设计有所变化。
画面像真实品牌发布会、品牌设计案例或高级产品目录。
比例 3:4 或 4:5，超高清
最终效果：
不是“把宠物印在商品上”，而是“真的为这只宠物创立了一个品牌”
```
