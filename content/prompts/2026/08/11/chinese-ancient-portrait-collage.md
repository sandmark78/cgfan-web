# 东方古风人物志 · 剪纸拼贴海报

**作者**: Larus Canus  
**日期**: 2026-08-10  
**评分**: 75/80

## Prompt

```
朝代：【】
人物身份：【】
代表服饰：【】
器物：【3–5件】
场景：【】
文化元素 / 纹样：【】
主色调：【】
中文标题：【】
英文副标题：【】

生成一张3:4东方古风人物志编辑拼贴海报。

以一名全身完整出镜的成年人物作为主视觉，人物必须高度写实，具有真实古风摄影质感：自然身体比例、真实皮肤与发丝、自然眼神和动作、真实服装材质与实景自然光影。服装需要同时具备【朝代】代表性与高级设计感，不要影楼戏服或古偶剧照感。

人物采用局部剪纸贴片效果：主要身体轮廓保留轻微不规则米白纸边与浅阴影，发丝、衣袖、持物手部和部分衣角自然融入拼贴，不要完整粗白边。

使用暖米白宣纸 / 旧图录纸张背景，围绕人物安排3组辅助拼贴：
1. 【场景】环境照片
2. 【器物】静物图录
3. 【文化元素 / 纹样】、书札、服饰纹理和研究资料

主人物保持完整色彩，辅助图片适当降低饱和度，并使用裁纸、撕纸、胶带、轻微旋转和叠压形成东方档案拼贴感。

顶部加入大号中文书法标题「【中文标题】」，搭配英文副标题"【英文副标题】"；加入朝代、身份、器物、色系、地点、Archive编号等小型图录信息，以及少量题签、批注和朱文印章。

整体保留25%–35%留白，最终效果像「真实古风人物写真 + 朝代器物图录 + 东方人物档案」融合而成的高级人物志海报。

避免CG感、塑料皮肤、仙侠特效、僵硬Pose、错误服饰、随机器物、拼贴过满、廉价古装感和粗白色贴纸边。
```
