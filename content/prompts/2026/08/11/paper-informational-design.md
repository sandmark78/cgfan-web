# 纸质信息设计 · 克制庄重的版面系统

**作者**: 小小东  
**日期**: 2026-08-10  
**评分**: 68/80

## Prompt

```
Build a restrained, solemn paper-based informational design with human warmth around any chosen thematic subject: let large areas of bright white space first establish quiet order, then let a striking headline, line-drawn narrative, and bottom numerals carry the reading onward in sequence. Organize clearly differentiated modules along a single main reading axis: near the top, place one extremely small, thin, widely letterspaced auxiliary text or numbering group on each side, separated by remote spacing to create slight asymmetry; beneath them, set an oversized, high-contrast Latin serif headline extending horizontally, with strong contrast between fine hairlines and thick stems, elongated letterforms, sharp terminals, and the same accent ink as the core illustration; then add a centered group of short Chinese phrases on the theme, built on a slender Songti skeleton with generous line spacing and breathing room between characters, so the dark text block both carries the headline and builds the illustration's lower boundary; below, place a single continuous thin-rule line drawing that narrates the subject in a calm, technical, almost architectural hand — fine nib, uniform weight, no shading, no cross-hatching, precise but humane; let the drawing occupy the full width and anchor the middle third of the page. Reserve the bottom margin for large, lightly spaced numerals or a single repeating word in a condensed sans, set in the same accent color as the headline, reading left to right like a footnote or page reference. Use only two ink colors — near-black for all body content and one warm accent (terracotta, oxblood, or deep ochre) — applied consistently to headline, numerals, and one small graphic element in the drawing. Paper stock: warm off-white, slight tooth, no gloss. Overall feel: a quiet, authoritative information page from a meticulously edited print annual — serious but not cold, structured but not rigid, minimal but never empty.
```
