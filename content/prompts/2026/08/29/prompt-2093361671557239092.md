## Prompt

【主题】：____
【中文主标题】：____
【英文标题】：____
【中心主体】：____
【压角方式】：异形色块压角 / 同侧双角夹压 / 材质切片压角 / 上下错位夹压
【压角元素】：色块 / 图像切片 / 材质样本 / 文字 / 结构面
【辅助视觉系统】：____
【背景信息层】：____
【主色调】：____
【辅助色】：____
【日期 / 机构】：____
【画面比例】：9:16

生成一张具有成熟文化展览与编辑设计气质的「压角构图」海报。核心不是简单把大型文字塞进四个角，而是利用色块、材质、图像切片、文字和版面结构，从画面边缘向内部施加视觉压力，在中心自然形成清晰的主体区域。

中心主体保持稳定、完整，占画面约 40%–60% 的视觉重量，不要为了体现压角而故意倾斜、扭曲或挤进角落。

根据选择的压角方式组织版面：异形色块压角，通过 2–4 块大小不同的色块从边缘切入，在中央留下不规则主体窗口；同侧双角夹压，让同一侧上下两个角同时向内施压，把主体自然推向另一侧；材质切片压角，使用与主题相关的岩层、织物、釉面、纸张等材质切片从边缘进入并围住主体；上下错位夹压，让顶部和底部的文字、色块或结构面错位向中央夹入，在中间保留纵向主视觉空间。

压角元素必须和主题本身有关。例如海岸主题可以使用地图色块、等高线和潮位数据；舞台主题可以使用幕布、剧场图纸和演出档案；地质主题使用岩层切片和剖面线；织物主题使用经纬结构、布料样本和织造图。

整张海报只保留一套主要辅助视觉语言，不要同时堆入多套无关装饰。背景也需要参与设计，可以加入与主题相关的极淡地图、结构图、材料纹理、档案文字或测量信息，让留白有层次，但远看仍然清楚。

文字建立明显层级：大型中文标题负责版面重量，中号标题建立主题，日期、机构、参数和说明使用极小字号，并集中在 2–3 个区域。不要让所有文字大小接近，也不要把小字平均撒满画面。

色彩控制在 3–5 个主要颜色，保持明确的色彩立场。整体信息密度中等偏高，但阅读顺序必须清楚：第一眼看到压角关系与主体，第二眼看到标题、色块或材质结构，第三眼再阅读日期、数据和辅助信息。

最终效果要像成熟的文化展览海报和编辑类设计：边缘有压力，中心有聚焦，丰富但不乱，有层次但不刻意。即使去掉所有小字，画面本身也应该是一件完整成立的视觉作品。

避免：四角平均用力、为了压角强塞大字、主体强行倾斜、随机色块、材质拼贴无逻辑、多套装饰系统混用、边缘全部塞满、商业模板感。
