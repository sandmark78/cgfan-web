# 餐饮品牌视觉系统全案板

**作者**: Larus Canus  
**日期**: 2026-08-02  
**评分**: 69/80 (9+8+8+10+8+9+8+9=69)

## Prompt

```
【品牌名】：填写
【英文名】：填写
【餐饮品类】：填写
【品牌定位】：填写
【主打菜品】：填写
【五连图内容】：填写5项
【套餐名称及价格】：填写
【推荐菜】：填写6项
【新鲜事主题】：填写
【主色调】：填写
【辅助色与点缀色】：填写
【材质与视觉风格】：填写
【画面比例】：3:4竖版

请为以上餐饮品牌生成一张"大众点评商户通装修物料概览案板"，用于前期视觉提案、客户确认和作品集展示。

画面一次性包含6类物料：
入口图、五连图、套餐图、推荐菜、菜单图、新鲜事图。

左侧设置一条窄竖栏，按顺序清晰标注：
入口图 / 五连图 / 套餐图 / 推荐菜 / 菜单图 / 新鲜事图。

顶部由品牌入口主视觉和独立案例信息卡组成。信息卡可包含：
"大众点评商户通物料视觉设计案例"
"RESTAURANT VISUAL SYSTEM"
以及品牌名、餐饮品类和年份等少量信息。

每类物料都要具备独立背景、清晰边界、完整构图和适当间距，可以单独拆分使用。菜品、装饰和背景元素不要跨越相邻模块，也不要与上下物料粘连。

整套视觉通过统一的品牌配色、字体、菜品摄影、器皿、边框、标签和装饰语言保持一致。各模块可以采用不同构图，但必须明显属于同一个餐饮品牌。

入口图突出品牌名、核心标题和主打菜；
五连图展示5个招牌菜或核心卖点；
套餐图突出套餐名称、价格和完整组合；
推荐菜用统一产品卡展示6道菜；
菜单图制作成独立的横向必点清单；
新鲜事图用于新品上市、季节限定或近期活动。

菜品使用真实、精致、有食欲感的商业餐饮摄影。食材纹理清楚，光线、器皿和场景符合品牌定位。主菜突出，辅助菜品层次明确，避免所有菜品大小和构图完全相同。

控制中文信息量，每个模块只保留主标题、简短菜名、价格和少量标签。确保缩略图状态下仍能快速识别核心内容。

避免：模块粘连、元素跨界、风格分散、背景混乱、菜品重复、摄影光线不统一、过多小字、中文乱码、廉价模板感、过度拥挤和装饰堆砌。

最终生成一张高完成度、可拆分、可继续细化的大众点评商户通餐饮视觉概览案板。确认整体风格后，再按平台规格拆分各个板块逐张完善。
```
