## Prompt

Create a premium 4:5 vertical ultra-HD miniature world poster for [COUNTRY / LOCATION / SUBJECT].

TEXT-TO-IMAGE ONLY — generate the entire composition creatively from [COUNTRY / LOCATION / SUBJECT] alone. No reference image required.

MAIN CONCEPT
Create a breathtaking floating miniature island shaped organically like [COUNTRY / LOCATION / SUBJECT], suspended high above a vast layer of soft white clouds. The landmass should clearly preserve the recognizable geographic silhouette while remaining visually natural and believable.

LANDSCAPE & IDENTITY
Automatically integrate the most iconic landmarks, architecture, natural landscapes, terrain, vegetation, waterways, and cultural elements associated with [COUNTRY / LOCATION / SUBJECT]. Select several recognizable features and arrange them naturally across the miniature terrain rather than creating a random collection of landmarks.

Add appropriate local wildlife and environmental details where visually relevant. Include tiny roads, villages, forests, coastlines, mountains, rivers, or other geographic features to create the feeling of a complete miniature world.

TEXT ELEMENT
Carve the exact name of [COUNTRY / LOCATION / SUBJECT] directly into the terrain using elegant large white 3D letters. The lettering should feel physically embedded into the landscape, not floating above it.

LIGHTING & ATMOSPHERE
Use cinematic golden-hour sunlight, realistic atmospheric haze, soft cloud illumination, vivid but natural colors, detailed terrain textures, realistic shadows, subtle sun reflections, and dramatic aerial depth.

STYLE
Hyper-realistic miniature world × cinematic aerial photography × premium travel poster × detailed geographic diorama. Emphasize realistic scale, convincing materials, natural landscapes, intricate miniature details, and an awe-inspiring sense of altitude.

Avoid random landmarks, distorted geography, impossible architecture, excessive text, cartoon styling, toy-like plastic appearance, flat terrain, artificial colors, clutter, logos, watermarks, or UI elements.
