## Prompt

🪿 Keep one eccentric hero portrait at center, then crop the scarf print, eyewear hardware, feather texture, and jewelry into edge-aligned detail boxes.
The accessories become inspectable without breaking the central image’s authority.
🍊 Give every inset one material and one short caption, using the same box size, border, and spacing rhythm.
The page reads like a real fashion spec sheet, so the styling feels designed as a system rather than assembled as costume.
