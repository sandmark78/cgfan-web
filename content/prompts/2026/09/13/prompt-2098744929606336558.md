# 中式巨物美学：汉服游居巨型花木间

**作者**: 九尾狐-FoxFairy🦊  
**日期**: 2026-09-12  
**评分**: 67/80 (9+8+8+9+9+7+9+8=67)

## Prompt

```
场景设定：【地点＋主要植物＋人物活动＋天气】。

生成一幅中式巨物美学画面，横向16:9构图，真实古装人物、细腻植物材质、东方诗意的电影光影。整个场景围绕一种主导植物展开，形成连续、可进入、可游居的自然空间；画面聚焦一个安静的生活瞬间。

【巨物与空间】
以人物作为明确的尺度参照，主要花叶的展开尺度达到人物身高的数倍至数十倍。巨型植物直接构成环境：叶面的起伏成为可行走的坡地，舒展的叶片成为休憩平台，低垂的叶冠形成天然屋盖，枝茎连接高低空间，弯曲花瓣承载水上活动。根据场景选用合适的结构，突出一个主要活动空间。植物保持清楚可辨的原始形态，巨物从人物脚下延伸到头顶与远处，局部超出画框，产生身处花木深处的包围感。
【人物与生活】
少量成年汉服女子自然融入环境，真实人体比例、自然面容、乌发与简洁发髻。衣裙以月白、浅青、淡粉为主，可用少量朱红点缀；轻纱透光，裙摆垂坠，宽袖与长披帛随风轻扬。人物专注于场景中的活动，通过行走、坐卧、撑篙、垂钓或品茶建立与巨物的联系。脚掌贴合承载表面，衣裙顺着叶面铺展，人物与植物之间有自然接触阴影。竹篮、团扇、竹梯、茶具等仅按活动需要出现，尺寸与人物匹配，共同衬托周围植物的巨大。

【镜头与构图】
摄影机置身人物所在的空间，以适度广角的中远景呈现人与巨物的关系。前景安排近距离花叶的局部遮挡，中景保留清晰的人物活动，远景通过交叠花叶、重复茎秆和空气透视延伸纵深。利用斜向枝茎、卷曲叶缘或高低花瓣组织视线。人物全身可辨，姿态自然，巨物主导画面；统一视点、光向与透视，保留舒展的空间和适量留白。
【材质与色彩】
巨叶具有清晰叶脉、细微褶皱、自然卷边和柔润蜡质反光；花瓣具有细密纵向纹理、柔软弧面、粉白渐变与薄处透光感。青绿、灰青、清透水蓝与莲粉、乳白形成和谐色彩关系，依场景调整占比，整体饱和度克制。使用符合天气的自然天光，保留深青叶影、明亮衣裙与透光花瓣之间的细腻明暗层次。水面出现时具有真实倒影和轻微涟漪，远景可有薄雾，主体清晰通透。

整体呈现古人游居巨大花木之间的闲适生活：空间壮阔，人物轻盈，气氛清雅、温柔、宁静。植物、人物、衣料和器物拥有统一的摄影质感，超现实尺度与真实生活细节自然融合。
负面提示词：普通尺寸植物，尺度差不明显，巨人，怪兽，恐怖氛围，植物建筑化，石雕花瓣，塑料材质，玩具小人，移轴沙盘，卡通动漫，过度磨皮，僵硬摆拍，悬浮人物，接触错误，穿模，肢体畸形，透视混乱，多场景拼贴，杂乱装饰，现代元素，霓虹光，法术光环，过度饱和，过度锐化，浓雾遮挡主体，文字，字幕，水印，短视频界面。
```
