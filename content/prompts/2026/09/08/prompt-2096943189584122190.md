# 自然力量可视化：潮声风光的人物海报

**作者**: Larus Canus  
**日期**: 2026-09-07  
**评分**: 67/80

## Prompt

```
生成一张 9:16 竖版高质量人物艺术海报，将一种"看不见或难以直接捕捉的自然现象"转化成画面的核心构图方式。

主题：[潮 / 声 / 风 / 光 / 其他自然现象]
人物：[人物性别、年龄、服装、姿态]
主标题：[中文标题]
英文标题：[英文标题]
主色：[主色系]
运动规律：[推进 / 回旋 / 卷绕 / 切割 / 扩散 / 折射等]

不要只是给人物背景添加自然特效，而要先理解这一自然现象真实的运动规律，再让它直接组织人物、空间、线条与视觉动势。

例如：
潮水可以用层层推进的曲线重新划分人物与空间边界；
声音可以用开放式回旋、波动与远近变化形成环绕结构；
风可以借助连续柔顺的织物、发丝或轻质材料显出流向；
光可以通过遮挡、缝隙、明暗切面与投影重新切割空间。

人物必须真正进入这一运动结构，而不是简单站在特效前方。

统一视觉风格：暖象牙色未涂布艺术纸背景，干净细腻的纸张纹理与轻微哑光印刷颗粒；真实自然的人物摄影质感；现代高对比中文 Typography + 优雅 Serif 英文标题 + 少量 Grotesk / Monospace 微信息；低饱和但完整的主题色，并保留极少量朱砂红作为系列视觉节点。

版面保持中高信息密度，但至少保留约 20% 有效留白。

最终让观众第一眼看到完整人物海报，第二眼意识到：画面的构图并不是人为添加的装饰，而是由这股自然力量自己的运动规律生成。
```
