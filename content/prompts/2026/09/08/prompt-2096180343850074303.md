# 中轴夹景：两侧视觉重量塑造中心

**作者**: Larus Canus  
**日期**: 2026-09-05  
**评分**: 66/80

## Prompt

```
【主题】：____
【中文主标题】：____
【英文标题】：____
【左侧主体】：____
【右侧主体】：____
【中轴内容】：标题 / 人物 / 植物 / 留白 / 其他____
【夹景方式】：圆弧负形 / 空间透视 / 柔性材质 / 双器配重 / 其他____
【背景主色】：____
【主体材质与风格】：____
【日期 / 场馆】：____
【画面比例】：9:16

生成一张具有强视觉冲击和高级文化展览气质的「中轴夹景」海报。

先建立一条明确、稳定的垂直中轴，再让【左侧主体】与【右侧主体】从画面两侧共同形成视觉重量，把主标题、人物、植物或留白区域推向中央。

左右主体必须足够大，靠近画面边缘并允许自然裁切，共同承担主要视觉重量。两侧可以在轮廓、大小、颜色、材质和细节上不同，但整体视觉重量必须平衡。

根据主题选择不同的夹景方式：圆形、弧形主体可利用轮廓共同夹出中央负形；建筑、屏风等空间主体可通过透视形成纵深中轴；织物、植物等柔性材料可通过自然弯曲形成柔性夹景；器物、人物或文物可通过左右配重强化中央标题。

中轴必须成为画面最重要的阅读区域。中文主标题使用大胆的大字号，可采用纵排、横竖混排、尺度变化、局部遮挡或与主体轻微穿插。

使用一个明确的大面积主色建立识别度。整体控制在 3–5 个主要颜色。

核心原则：不是简单"左右对称"，而是利用两侧视觉重量共同塑造中心。左右负责施压，中轴负责聚焦。
```
