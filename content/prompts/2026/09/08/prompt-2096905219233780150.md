# 自然运动可视化：风潮雨光的汉字海报

**作者**: Larus Canus  
**日期**: 2026-09-07  
**评分**: 67/80

## Prompt

```
【自然现象】：____
【核心汉字】：____
【作品标题】：____
【英文标题】：____
【运动规律】：____
【主色】：深靛蓝 / 灰蓝 / ____
【强调色】：朱砂红
【作品短句】：____
【比例】：9:16

生成一张 Contemporary Asian Editorial Design 风格的文化展览海报。

先提炼【自然现象】最独特的运动规律，再让这个规律直接决定构图。不要只画现象本身。

以巨大的【核心汉字】作为第一视觉，并让汉字真正参与运动：被轨迹环绕、被力量穿过、被雨痕冲刷、被光影切割、从负空间显现。

统一使用暖象牙艺术纸、深靛蓝 / 灰蓝大色形、极少朱砂节点；中文采用现代高对比宋体，英文使用 Serif，小型观察信息使用 Grotesk / Monospace。

加入少量与主题有关的时间、方向、距离、角度、强度或环境记录，作为第三层细节。信息密度中高但杂而不乱，保留约 20% 有效留白。

第一眼看到核心力量，第二眼看到运动路径，第三眼发现观察信息，最后阅读作品标题与短句。

避免：普通风景海报、天气 App、科技 HUD、模板文字、满版书法、随机小字、Logo、编号、二维码和无意义装饰。
```
