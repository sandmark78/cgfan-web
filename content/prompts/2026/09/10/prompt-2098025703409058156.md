# 三分法跨区互动：东方文化展览海报

**作者**: Larus Canus  
**日期**: 2026-09-10  
**评分**: 65/80

## Prompt

```
【主题】：
【主视觉对象】：
【中文核心字】：
【中文标题】：
【英文标题】：
【物理关系】：投影 / 反射 / 转印 / 覆盖揭示 / 其他
【档案信息】：结构图 / 材料 / 尺寸 / 过程 / 局部样本 / 其他
【主题色】：
【画面比例】：9:16

生成一张具有成熟 East Asian Editorial Design、Museum Poster 与文化出版物质感的竖版海报。

使用“非均衡三分构图”，让画面中的三个区域分别承担：

1. 主视觉对象
2. 巨型中文标题
3. 档案与辅助信息

不要平均切成三栏，也不要画明显分割线。

最重要的是，根据【物理关系】设计至少一处真实的跨区互动，让三个区域产生因果关系：

例如主体产生放大投影、镜面反射文字、印刷纸从版面揭起、拓片卷起露出原件等。

不要只是让元素彼此靠近，要让它们真正发生遮挡、穿插、反射、转印或前后揭示。

整体使用暖象牙色未涂布艺术纸，搭配墨黑 Typography 和一个主要主题色。中文采用现代高对比宋体 / 明朝体，英文标题使用 Serif，小型档案信息使用 Grotesk / Monospace。

主视觉必须具有明显大形，缩略图也能成立。巨型【中文核心字】要参与空间关系，可以被影子穿过、被镜面反射、出现在印刷结果中，或与真实物体形成前后层级。

加入与主题真正相关的【档案信息】，例如材料、尺寸、工艺步骤、结构剖面、表面样本或观察记录，让海报既有视觉冲击，也有内容深度。

信息密度保持中高，但至少保留约 20%–30% 有效留白，形成“主视觉高密、档案中密、纸面低密”的节奏。

最终阅读顺序：

第一眼看到强主视觉与巨大中文；第二眼发现跨区的物理关系；第三眼理解结构、材料或过程；第四眼阅读作品标题与档案信息。

同系列统一纸张、字体体系、信息层级和编辑气质，但每张根据不同【物理关系】重新设计构图，不做模板换皮。
```
