# 竖三栏东方文化展览海报

**作者**: Larus Canus  
**日期**: 2026-09-09  
**评分**: 67/80

## Prompt

```
【主题】：
【中文标题】：
【英文标题】：
【核心主体】：
【三栏关系】：人物跨栏 / 同一主体三栏变化 / 中栏主景 / 器物跨栏 / 其他
【左栏内容】：
【中栏内容】：
【右栏内容】：
【主色调】：
【日期 / 场馆】：
【画面比例】：9:16

生成一张高审美、高信息密度的东方文化展览海报，采用「竖三栏 / 左中右构图」。

三栏不要平均分割，也不要做成三个独立信息框。根据主题灵活调整宽度，让每一栏承担不同视觉职责，再通过主体、文字、线条或材质主动跨越栏线，把三个区域重新连接成一个完整画面。

可根据内容选择不同方式：

人物跨栏：人物主要位于中栏，衣袖、裙摆或饰物进入左右栏，让左侧负责纹样与材质，右侧负责结构与档案信息。

同一主体三栏变化：让一件连续主体同时穿过三栏，在不同栏位呈现不同材质、阶段或状态，但轮廓必须连续，不能变成三个独立物体。

中栏主景：中央栏放置最强主视觉，例如山体、建筑或大型图像，左右栏承担标题、日期、材质、研究信息，并允许部分主体或云雾越栏。

器物跨栏：大型器物从一侧斜向或横向进入其他栏位，用主体本身打破竖向网格，让三栏只是排版秩序，而不是物理边界。

Typography 根据每张画面的结构重新设计，可使用超大单字、完整横排标题、跨栏标题、中等尺度标题或小型信息脊柱。不要固定使用四字纵排，也不要重复“两字横排 + 两字竖排”的模板。

信息密度要接近成熟博物馆海报、艺术图录和 Editorial Design：加入英文副标题、材质、结构、日期、场馆、策展短句和少量研究图，但集中在 2–3 个区域，不要平均铺满全画面。

可以加入小型结构线稿、材质研究、制作流程、剖面或纹样研究，但面积保持克制，只作为第二层阅读内容。

色彩使用 3–5 个主要颜色，以大面积纯净色域形成明显栏位关系。允许黑、骨白、朱红、钴蓝、深青、赭色等组合，但避免脏灰、严重做旧和复杂渐变。

整体要求：高清、清晰、干净、信息丰富但有秩序，主体比例准确，文字与细线锐利，具有成熟文化展览海报完成度。

避免：机械三等分、三个独立卡片、PPT 信息框、固定标题模板、主体过小、栏位完全割裂、随机小字、无意义装饰线、过度做旧、斑驳噪点和低完成度 AI 海报感。
```
