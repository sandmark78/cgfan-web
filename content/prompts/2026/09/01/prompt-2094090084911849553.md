## Prompt

【古诗名句】：填写一句具有强画面感的诗句
【两字主题】：从诗句中提炼 2 个核心字
【核心构图】：竖线与圆 / 点与面 / 斜线与三角 / 横线与小点 / 其他
【视觉主体】：孤烟 / 落日 / 孤城 / 云帆 / 孤舟 / 人物等
【点缀色】：朱红 / 群青 / 墨蓝 / 暖金等
【浅压纹】：沙丘 / 山脉 / 风痕 / 水纹 / 雪地路径等
【地点与日期】：填写

生成一张 9:16 竖版东方诗意留白海报，将【古诗名句】中的空间关系提炼成【核心构图】，不要直接复刻完整古诗场景。

使用纯白或浅冷白高级手工艺术纸作为背景，保留真实纸纤维、纸浆颗粒和细腻压痕。画面保持约 70% 的有效留白，让主体面积尽量克制，用少量元素形成明确视觉重心。

将【视觉主体】简化成清晰的线、点、圆、三角、色块或横向结构，通过比例、方向和位置关系表现诗句里的空间张力。主体不需要巨大，但缩略图中必须容易识别。

背景加入与诗句相关的低对比【浅压纹】，例如白色山脉、沙丘、风线、江面、雪痕或地貌结构。压纹要有一定可见度，但不能过重，主要依靠纸面高度、柔和侧光与细微阴影呈现，远看简洁，近看有细节。

使用【点缀色】建立单一而强烈的视觉锚点，例如一轮朱红落日、一座红色孤城、一张群青云帆或一点朱红浮漂。不要大面积铺色，让高饱和颜色与白色留白形成明显反差。

可加入极小人物、驼队、小舟等建立尺度关系，但数量必须少，避免复杂叙事。

所有风线、水线、烟线和地貌边缘都要连续、柔和、自然，避免大量断点、碎线和杂乱 AI 纹理。

中文主标题使用【两字主题】，采用现代宋体、明朝体或具有编辑感的中文衬线字体，可根据构图加入细线、轻微错位或方向呼应，但必须保证汉字完整、准确、清晰。同时加入小字号诗句、地点、日期和简短英文标题。

整体效果应像古诗空间意象、极简构图、纸张浅浮雕与现代 Editorial Design 的结合：远看有明确视觉张力，近看才能发现隐藏在留白里的山水、风雪与空间细节。
