# 东方诗意流光留白海报模板

**作者**: Larus Canus  
**日期**: 2026-09-25

## Prompt

```
【诗词原句】：填写与月亮相关的诗句
【两字主题】：从诗句中提炼
【月光动作】：升起 / 连接 / 环绕 / 回流 / 穿透
【小场景】：亭台 / 小舟 / 玉盘 / 暖窗 / 海面等
【流光颜色】：月白 / 银白 / 冰蓝 / 淡金等
【背景压纹】：月晕 / 云气 / 山河 / 水纹 / 玉纹等
【地点与日期】：填写

使用 GPT-Image2.5 生成一张 9:16 东方诗意流光留白海报。

背景使用纯白或月白高级手工艺术纸，保留真实纸纤维、细腻纸浆颗粒和自然压痕，整体保持约 65%–75% 的有效留白。

画面以一轮完整满月作为主要视觉锚点。加入一个面积克制、轮廓清晰的【小场景】，场景可以更风格化，介于东方剪纸、漆艺、玉雕、微缩建筑和现代装置之间，让小场景在大片白色留白中足够醒目。

加入 2–5 缕细长、连续、半透明的月色流光，通过【月光动作】连接月亮、留白和小场景。流光使用【流光颜色】，必须柔和、轻盈、有方向感，边缘自然。

背景加入低对比【背景压纹】，例如月晕、云气、山脊、水纹、道路或玉石纹理。压纹要有明确含义，并主要依靠纸面高度、柔和侧光和细微阴影表现，远看保持简洁，近看才发现细节。

整体色彩以纯白、月白、珍珠银为主，可使用深靛蓝、墨青或青玉绿建立小场景结构，再用极少量暖金、琥珀黄作为人间灯火和情绪焦点。

中文主标题使用【两字主题】，采用现代宋体、明朝体或高级编辑感衬线字体，可配合圆弧、细线和月晕增加轻度设计感，保证文字完整、准确、清晰。

同时加入小字号【诗词原句】、地点、日期和简短英文标题。

整体效果应像东方诗词、白色浅浮雕纸艺、月光材料实验、微缩场景装置与高级 Editorial Design 的结合：第一眼看到满月与流光，第二眼看到风格化小场景，近看才发现隐藏在白色留白中的压纹细节。
```

## 核心美学

- **流光留白**：65%-75% 有效留白，月光流光连接视觉元素
- **纸艺质感**：真实纸纤维、细腻纸浆颗粒、自然压痕
- **东方诗意**：诗词原句、宋体排版、月晕压纹
- **微缩场景**：剪纸/漆艺/玉雕风格的小场景装置
