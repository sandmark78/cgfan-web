# 春节·巨灯笼垂落

**作者**: 小小东  
**日期**: 2026-09-25

## Prompt

```
围绕春节灯笼生成一张具有巨大尺度感与清透留白的视觉画面：让灯笼被极度放大，像柔软而有纹理的垂落结构从画面上方压近，占据最大视觉重量，边缘形成连续的弧形遮蔽与窄缝透光；中部保留一条强烈明亮的呼吸带，微小人物提着春联安静穿过，使巨灯笼与小人物之间产生一眼可读的反差。下方用透明、反光、轻微波动的冰面承接灯笼与光源，倒影被拉长、散开，前景逐渐变深并保持柔焦层次，让空间像被光雾和水汽托住。色彩从春节的材质、情绪与文化语义中提取，映射为大面积干净的朱红与金色冷暖结构场、明亮高明度的透光底色、低饱和的暖橙次级支持色、少量清晰而克制的大红强调色，以及高对比但不刺眼的白色信息文字色；保持清透安静、明亮洁净、透明层次分明，避免浑浊旧化。文字如需出现，以稀疏、轻薄、宽字距的现代信息层悬浮在反射空间前，主标题"春节"大而浅，副信息更小更集中，整体留出充足空白，所有信息服从巨灯笼遮蔽、亮隙、微小人物与反射介质构成的第一视觉瞬间。
```
