# 虎小象·中秋主题创作

**作者**: 虎小象  
**日期**: 2026-09-24  
**评分**: 62/80

## Prompt

```
生成9张中秋主题的高级海报系列，每张独立成图，不做九宫格拼贴。

核心精神：圆，不只是月亮的形状，也是人与人、人与自己、人与时间重新靠近的一种状态。

中秋不是传统节日符号的堆砌，它更深层的精神是：圆满、想念、团聚、停顿、共享、抬头看向同一轮月亮时的情绪共鸣。

创作原则：
- 固定的是中秋的情绪结构，不固定中秋必须长成什么样
- 不要列举传统节日元素，不要拆成九种预设风格
- 建立精神场：团圆、圆满、想念、共享、月光、停顿、温柔、东方情绪、现代审美
- 让模型在这个场里自由生长出九张不同的画面

视觉方向：
- 温柔、安静、团聚感、想念感、克制、清透、松弛、圆满感、有留白、有情绪余韵
- 高级但不冷漠，东方气质但不古风模板化，时尚但不摆拍化，现代但不失文化气息
- 有节日感但不俗套喜庆，像高端生活方式campaign，像editorial海报

通过关系表现中秋，而不是通过符号：
- 圆与缺之间的对照
- 远与近之间的情绪连接
- 热闹与安静之间的平衡
- 团聚与想念同时成立
- 时间暂停片刻的感觉

文化转译（高级转译，不是直白复刻）：
- 月亮：转化为圆满感、柔和光源、情绪核心
- 团圆：转化为共享、靠近、同在
- 思念：转化为留白、距离感、看向远方
- 月饼：转化为圆形结构、共享食物、分享动作
- 灯笼：转化为柔和暖光、点状光源
- 玉兔/嫦娥：转化为轻微神话感、诗意、幻想余韵

色彩系统：
- 整体低至中等饱和度
- 月白、米白、浅灰、雾蓝、深靛蓝、灰青、柔和金、陶土色、浅棕、墨绿、炭灰
- 允许少量暖黄、金色、杏色作为节日温度点缀
- 避免婚庆红金、廉价古风配色、过度梦幻紫粉色

画幅：9:16竖版

约束：
- 不要传统中秋模板海报
- 不要红金喜庆主视觉
- 不要古风插画套版
- 不要玉兔嫦娥直白复刻
- 不要月饼礼盒广告感
- 不要把月亮做成唯一巨大主角反复复制
- 不要九张共享同一种场景骨架
- 不要廉价梦幻滤镜
- 不要民俗符号堆砌
```
