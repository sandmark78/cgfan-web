## Prompt

我把角色照片发给 YouArt，它就自动生成了好几张不同角度的人脸图，用来做「人脸元素（Face Element）」，给转身和甩头的动作补上参考。

3. 成片

补上人脸参考，确认效果没问题后，我换用 Seedance 2.5 生成了这条 28 秒的竖屏成片。

这条视频前后也就花了二十几分钟。我主要就是挑对标、准备人物素材，看片时再告诉 YouArt 哪里要改。

我觉得 YouArt 最厉害的是，从复刻到修脸，我全程没写提示词，直接跟它说我想要什么就行。

怎么做交由 Agent 跑通，但做什么、好不好，依然靠人来做审美和价值判断。

YouArt 客户端传送门👉🏻 https://youart.ai?invite=yvgvhi

七、最后

这套方法能帮你解决冷启动阶段“第一条发什么、怎么做出来”的难题。

对标表、拆解模板和二创清单，我都放到了开源仓库里。里面还有一个我做的 Skill，叫 viral-benchmark，可以帮你快速整理对标、拆视频。

支持 Skill 的 Agent 都能用。把找好的对标链接或本地视频丢给它，它会先帮你筛一遍，把结果整理成表，再拆一下值得做的几条，看看哪些地方可以借。

仓库链接放评论区，模板和 Skill 都可以直接拿去用。

另外，我也把这个 Skill 上传到了 YouArt 技能市场，搜索「爆款对标拆解」就能在 YouArt 里直接用。
