## Prompt

5 min read

最近全网都在刷屏 Vogue 风格的红毯高定变装视频：极具戏剧张力的气球爆裂换装、密集的红毯长焦闪光灯，再到纯黑棚拍里子弹时间的巨型裙摆绽放与回眸一笑。

先看成片👇

以前要用 AI 复刻这种多机位、强节奏的商业短片，光是抽卡、写十几条运镜 Prompt、对齐人物面部一致性，再去剪映里手动卡点配乐，至少要折腾大半天，真的是一件非常麻烦的事情。

这次我实测 YouArt 的 /Viral Remake（爆款复刻）工作流，用的是目前最强模型Fable 5.2 ：只用了 3 张静态参考图 + 原片参考视频，它就自动拆解了全套分镜和配乐。更惊艳的是——当第三段生成效果不满意时，不用全片重抽，而是用对话局部重拍，甚至能跨镜头引用表情，最终一步到位拿下了这条 36 秒的丝滑成片。

下面把这套零门槛、高可控的复刻全流程完整拆解给大家👇

一、前期准备：只用 3 张“锚点图”锁定全场审美

想要全片人物不崩、服化道质感在线，核心在于给 AI 喂入高质量的首尾关键帧锚点图。这次我只准备了 3 张核心资产：

图1 · 变装前造型：T台追光下，身穿浅蓝色百褶短裙搭配米白色小香风外套的甜美少女，作为开场第一帧的视觉锚点。
图2 · 变装后高定红毯：同款清冷精致面孔，换上一袭华丽的层叠蕾丝粉色高定大礼服，手牵巨大的玫瑰金气球，奠定第二幕的名利场氛围。
图3 · 黑场旋转绽放：纯黑背景下，少女站在白色方台上旋转，粉色巨型纱裙在空中展开出完美的波浪弧度，作为第三幕的视觉高潮。
少即是多：3 张高审美关键帧，就足以锁定全片色调和人物一致性，动态过渡交给 AI 理解。
 二、第一步：启动 /Viral Remake，全自动扒片与分镜生成

打开 YouArt，不需要写繁琐的运镜参数。直接调用 /Viral Remake 技能，把 3 张参考图 + Vogue 原片参考视频一起丢给 Agent，只输入这一句：

Prompt 1
/Viral Remake 理解这个参考视频，根据图片复刻这个视频，要好看，电影般丝滑的运镜，严格按照参考视频上的风格来，但全程整片不要文字

YouArt 接收到指令后，展现了非常老练的“导演级”拆解能力：

逐帧扒片：它先完整看了一遍参考视频，提炼出核心骨架（气球爆开换装 → 闪光灯红毯 → 黑场旋转 → 定格），并逐帧核对镜头与切点。
四线并发与环境自适应：自动拆解出 3 个核心镜头任务 + 1 条定制配乐（Pink Runway）同步生成。期间镜头 1 和 3 因为参考图被识别出高精度人脸，Agent 自动帮我打开了“真人面孔模式”开关并重新提交任务，完全不需要人工排查报错。

第一版初剪出来后，前两段直接封神：

第一段（00:00-00:05）：少女吹大粉色泡泡糖，气球瞬间爆开炸出漫天粉色烟雾与花瓣，烟雾散去丝滑切换成粉色高定礼服，物理流体质感极佳。
第二段（00:06-00:23）：背景无缝切入长枪短炮的摄影师闪光灯矩阵，镜头在正面特写、气球飘过前景遮挡、撩发微笑与回眸杀之间高频切换，尤其是第 12-16 秒的回眸一笑，眼神灵动自然，充满星味。
三、第二步：导演级“局部返工”，用大白话拯救子弹时间（核心亮点！）

虽然前两段很惊艳，但初版成片的第三部分（子弹时间段）却踩了传统 AI 视频的通病：转场是生硬的硬切、螺旋环绕运镜显得杂乱，最致命的是模特最后的笑容非常僵硬（露齿假笑）。

放在以前，这意味着要重新抽卡、重新剪辑。但在 YouArt 里，我直接在对话框里像审片导演一样指出问题，甚至让它拿第二段的好表情去救第三段：

Prompt 2（修正指令）
第三部分不太好，分析参考视频，要严格按照参考视频上的转场运镜等参数，要好看，笑容也太僵硬，参考一下刚刚生成的第二部分的笑容，要好看自然

看看 YouArt 是如何精准执行这次“外科手术式”重拍的：

它先把参考片第三部分逐帧拆开，只针对镜头 3 重新开拍，并自动完成了重新剪辑（贴心地生成了「成片 v2 · 第三部分重拍 36s」，同时保留旧版方便对比）。

针对我的反馈，它在底层精准执行了 4 项核心修正：

转场重塑：把上一版的直接硬切，改成了红毯段末尾闪白 → 接约 0.3 秒纯黑停顿 → 再切进黑场，呼吸感瞬间拉满。
运镜矫正：去掉了上一版杂乱的螺旋环绕，改成一镜到底的直线推近——开头远景几乎不动，随后加速推近并压低机位，在裙摆绽放时贴着裙摆掠过，最后缓推到半身稳稳停住。
表演微调：旋转一圈多后，趁着层叠粉色纱裙缓缓落下的物理惯性，人物背侧对镜头自然回眸，笑意慢慢浮现。
跨镜头表情迁移：直接提取了第二部分那个惊艳的回眸微笑画面作为参考锚点，将原本僵住的露齿大笑，替换成了松弛的抿嘴笑，甚至还原了眨眼和眼神流转的微表情！
做长视频最怕“牵一发而动全身”。先让 Agent 跑出全片分镜，再针对拉胯的单镜头单独重拍，不用全片重抽。
四、实战总结：为什么这套工作流值得抄作业？

看完最终合成的 36 秒成片，从开场气球爆裂、红毯闪光灯洗礼，到 00:24 子弹时间的纯黑停顿后一镜到底推向旋转盛开的粉色裙摆，再到最后定格的绝美回眸，节奏与情绪完全复刻了 Vogue 原片的灵魂。

总结这次实测的 3 个核心心得：

以图控场，少即是多：3 张高审美关键帧足以锁定全片色调与人物一致性，把动态过渡交给 AI 理解。
告别盲盒，局部迭代：做长视频最怕“牵一发而动全身”。先让 Agent 跑出全片分镜大纲，再针对拉胯的单镜头单独重拍，能省下大约 80% 的算力和时间。
善用上下文资产复用：当某一段抽出了神级表情或光影（比如本片第二段的微笑），可以直接在对话里要求 Agent 将其作为参考标准迁移到其他分镜中，实现全片质感对齐。
