## 偏好总结

### 最喜欢的共同特征
1. **叙事性强** - 有故事感，不是单纯展示
2. **电影感** - 光影戏剧性，有氛围
3. **东方美学** - 禅意、留白、传统元素
4. **复古未来主义** - 科幻+怀旧结合
5. **框架类提示词** - 结构化、模板化
6. **有限配色** - 2-3色，克制不花哨
7. **建筑+自然融合** - 人造与自然的对话

### 一般的共同特征
1. **纯商业产品** - 缺乏叙事深度
2. **构图偏满** - 信息过多，缺乏留白
3. **可爱/卡通风** - 与审美偏好不符
4. **过于写实** - 缺乏艺术处理
5. **题材不符** - 室内设计、时尚人像等
